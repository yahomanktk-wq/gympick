## 2단계: 줌 기능 구현

### 구현 방식 선택 기준

**Case A: react-native-gesture-handler가 이미 설치된 경우**
→ `PinchGestureHandler`를 사용해 구현

### Case A: PinchGestureHandler 방식

#### 설치 확인 (이미 있으면 생략)
```
npx expo install react-native-gesture-handler
```

#### WorkoutCameraOverlay.tsx 수정 사항

1. imports 추가:
```tsx
import { PinchGestureHandler, PinchGestureHandlerGestureEvent, State } from 'react-native-gesture-handler';
import Animated, { useSharedValue, useAnimatedStyle, withSpring } from 'react-native-reanimated';
```

2. zoom 상태 추가 (컴포넌트 최상단):
```tsx
const zoom = useSharedValue(0);           // CameraView zoom: 0~1
const lastZoom = useSharedValue(0);       // 이전 줌 값 보존용
const MIN_ZOOM = 0;
const MAX_ZOOM = 0.8;                     // 너무 많이 당기면 화질 저하
```

3. 핀치 핸들러:
```tsx
const onPinchGestureEvent = (event: PinchGestureHandlerGestureEvent) => {
  const scale = event.nativeEvent.scale;
  // scale 1.0 = 변화 없음, >1 = 줌인, <1 = 줌아웃
  const delta = (scale - 1) * 0.015;
  const newZoom = Math.min(MAX_ZOOM, Math.max(MIN_ZOOM, lastZoom.value + delta));
  zoom.value = newZoom;
};

const onPinchStateChange = (event: PinchGestureHandlerGestureEvent) => {
  if (event.nativeEvent.state === State.END || event.nativeEvent.state === State.CANCELLED) {
    lastZoom.value = zoom.value;
  }
};
```

4. CameraView를 PinchGestureHandler로 감싸기:
```tsx
<PinchGestureHandler
  onGestureEvent={onPinchGestureEvent}
  onHandlerStateChange={onPinchStateChange}
>
  <Animated.View style={{ flex: 1 }}>
    <CameraView
      ref={cameraRef}
      style={StyleSheet.absoluteFill}
      facing="back"
      flash={flash}
      zoom={zoom.value}   // ← zoom prop 연결
    />
    {/* 기존 오버레이 요소들 유지 */}
  </Animated.View>
</PinchGestureHandler>
```

### Case B: PanResponder 방식 (react-native-gesture-handler 없을 때)

#### WorkoutCameraOverlay.tsx 수정 사항

1. imports 추가:
```tsx
import { PanResponder } from 'react-native';
```

2. zoom 상태 추가:
```tsx
const [zoom, setZoom] = useState(0);
const lastZoom = useRef(0);
const initialDistance = useRef<number | null>(null);
```

3. 두 터치 포인트 간 거리 계산 함수:
```tsx
function getDistance(touches: React.Touch[]): number {
  const [a, b] = touches;
  const dx = a.pageX - b.pageX;
  const dy = a.pageY - b.pageY;
  return Math.sqrt(dx * dx + dy * dy);
}
```

4. PanResponder 생성:
```tsx
const pinchResponder = PanResponder.create({
  onStartShouldSetPanResponder: (evt) => evt.nativeEvent.touches.length === 2,
  onMoveShouldSetPanResponder:  (evt) => evt.nativeEvent.touches.length === 2,
  onPanResponderGrant: (evt) => {
    if (evt.nativeEvent.touches.length === 2) {
      initialDistance.current = getDistance(evt.nativeEvent.touches as any);
    }
  },
  onPanResponderMove: (evt) => {
    if (evt.nativeEvent.touches.length === 2 && initialDistance.current !== null) {
      const currentDist = getDistance(evt.nativeEvent.touches as any);
      const ratio = currentDist / initialDistance.current;
      const delta = (ratio - 1) * 0.3;
      const newZoom = Math.min(0.8, Math.max(0, lastZoom.current + delta));
      setZoom(newZoom);
    }
  },
  onPanResponderRelease: () => {
    lastZoom.current = zoom;
    initialDistance.current = null;
  },
});
```

5. CameraView에 PanResponder와 zoom 연결:
```tsx
<View style={{ flex: 1 }} {...pinchResponder.panHandlers}>
  <CameraView
    ref={cameraRef}
    style={StyleSheet.absoluteFill}
    facing="back"
    flash={flash}
    zoom={zoom}
  />
  {/* 기존 오버레이 요소들 유지 */}
</View>
```

## 3단계: 주의사항

- CameraView에 zoom prop이 없는 expo-camera 버전이라면 `zoom` 대신 `zoomFactor` prop을 시도한다
  (버전별 prop 이름이 다를 수 있음 — 실제 파일 확인 후 맞는 prop 사용)
- 기존 "화면 탭 → 촬영" 로직(TouchableOpacity 또는 onPress)은 절대 변경하지 않는다
- 오버레이 요소(헬스장명, 머신 목록, 날짜, 텍스트컬러)는 절대 변경하지 않는다
- 플래시 토글 버튼 위치/동작 변경 금지
- MachineCard.tsx 변경 금지
- 컬러 시스템(C, R, T) 변경 금지

## 4단계: 동작 확인 체크리스트

1. 카메라 뷰파인더에서 두 손가락으로 벌리면 줌 인 ✅
2. 두 손가락으로 오므리면 줌 아웃 ✅
3. 핀치 동작 종료 후 zoom 레벨 유지 ✅
4. 화면 탭(한 손가락)은 기존대로 촬영 동작 ✅
5. 오버레이(헬스장명, 머신, 날짜)는 줌 중에도 정상 표시 ✅
6. 다시 찍기 후 재진입 시 zoom이 0으로 초기화 ✅ (컴포넌트 재마운트로 자동 처리됨)
