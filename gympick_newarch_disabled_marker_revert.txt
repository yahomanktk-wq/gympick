[배경]
현재 GymMapView.tsx는 마커 라벨을 좌표 기반 오버레이 View로 그리는 방식으로 바뀌어 있음.
텍스트 잘림은 해결됐지만, 지도 드래그 시 마커가 고정되어 있다가 뚝 점프하는 UX가 좋지 않음.

근본 원인: React Native 새 아키텍처(Fabric)에서 tracksViewChanges prop이 안드로이드 네이티브
코드에 매핑이 안 되는 react-native-maps 라이브러리 버그. tracksViewChanges가 동작하면
기존 <Marker> 방식(지도랑 같이 부드럽게 움직임)에서 500ms 타이머로 텍스트 잘림을 해결할
수 있음.

해결 방향: app.json에 "newArchEnabled": false를 추가해서 새 아키텍처를 비활성화 →
tracksViewChanges가 다시 동작 → GymMapView.tsx를 다시 <Marker> 방식으로 되돌리고
tracksViewChanges 500ms 타이머 유지.


[1] app.json 수정 (실제로 코드 수정)

app.json의 "expo" 객체 최상위에 다음을 추가해줘:
"newArchEnabled": false

다른 항목은 건드리지 마. 수정 전/후를 보여줘.


[2] GymMapView.tsx를 <Marker> 방식으로 되돌리기 (실제로 코드 수정)

현재 오버레이 방식으로 바뀐 GymMapView.tsx를 다시 <Marker> 기반으로 되돌려줘.
되돌린 후의 최종 상태가 다음을 모두 만족해야 해:

1. gyms.map()에서 각 헬스장에 대해 <Marker>를 렌더링하고, 그 안에 기존처럼 View(아이콘 +
   Text 라벨) 형태의 커스텀 마커를 그림.

2. tracksViewChanges 상태 + 500ms 타이머가 유지되어 있어야 함:
   const [tracksChanges, setTracksChanges] = useState(true);
   useEffect(() => {
     setTracksChanges(true);
     const t = setTimeout(() => setTracksChanges(false), 500);
     return () => clearTimeout(t);
   }, [gyms]);
   <Marker ... tracksViewChanges={tracksChanges}>

3. truncateGymName 헬퍼(maxLen=6)와 ellipsizeMode="clip"이 Text에 적용되어 있어야 함
   (안전망으로 유지).

4. markerText 스타일의 maxWidth는 100으로 유지.

5. 오버레이 방식에서 추가됐던 코드들(markerPositions state, pointForCoordinate 호출,
   position:'absolute' 오버레이 View, onRegionChangeComplete 좌표 재계산 등)은
   전부 제거해줘.

6. 사용자 위치 마커(있다면)나 선택된 헬스장 카드 등 마커와 무관한 다른 기능들은
   그대로 유지해줘.

수정 전/후를 빠짐없이 보여줘.


[3] 최종 확인 (코드 레벨 셀프 체크)

수정 후:
- app.json에 "newArchEnabled": false가 추가됐는지
- GymMapView.tsx에 오버레이 관련 코드가 남아있지 않은지
- tracksViewChanges={tracksChanges}가 <Marker>에 붙어있는지
- truncateGymName, ellipsizeMode="clip"이 Text에 있는지
위 4가지를 직접 확인하고 결과를 알려줘.
