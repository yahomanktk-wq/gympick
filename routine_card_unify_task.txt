# 태스크: 운동일지 상세화면 루틴카드를 운동사진 단계 저장 카드와 동일하게 수정
# 프로젝트 경로: D:\시작\gympick
# 확인이나 중단 없이 끝까지 완료해줘

---

## 변경 목표

운동일지 상세화면(JournalScreen)의 루틴카드를
운동사진 단계에서 저장되는 루틴카드와 동일하게 맞춘다.

| 항목 | 현재 (상세화면) | 변경 후 |
|------|------|------|
| 날짜 형식 | Tuesday, May 26, 2026 | 2026-05-26(Tue)_21:06 |
| 테두리 색상 | C.border (회색) | session.overlayTextColor (#ffffff 기본) |
| 헤더 부위 칩 | 없음 | muscles 데이터 기반 칩 추가 |
| PR 뱃지 | 라임그린 PR 뱃지 | 제거 |

---

## 수정 파일 4개
1. `src/data/types.ts` — WorkoutLog 타입에 overlayTextColor 추가
2. `src/lib/db/workouts.ts` — insertWorkoutSession에 overlay_text_color 저장
3. `src/lib/db/index.ts` (또는 fetchWorkoutLogs 위치 파일) — fetch 시 overlay_text_color 읽기
4. `src/screens/flow/PostWorkoutLogModal.tsx` — workoutLog 생성 시 overlayTextColor 포함
5. `src/screens/JournalScreen.tsx` — 루틴카드 UI 수정

## 3단계: src/lib/db/workouts.ts — insertWorkoutSession 수정

`insertWorkoutSession` 함수를 찾아서 `overlay_text_color` 컬럼을 insert에 포함한다.

함수 파라미터 타입에 추가:
```ts
  overlayTextColor?: string;
```

Supabase insert 객체에 추가:
```ts
  overlay_text_color: overlayTextColor ?? '#ffffff',
```

## 4단계: fetchWorkoutLogs — overlay_text_color 읽기

`fetchWorkoutLogs` 함수가 있는 파일을 찾는다 (`src/lib/db/index.ts` 또는 `src/lib/db/workouts.ts`).

Supabase select 쿼리에서 `workout_sessions` 테이블을 가져오는 부분에
`overlay_text_color` 컬럼이 포함되도록 확인한다.

select 문이 `select('*')` 이면 자동으로 포함되므로 별도 수정 불필요.
특정 컬럼만 명시하는 경우 `overlay_text_color` 를 추가한다.

fetch 결과를 WorkoutLog로 매핑하는 부분에 아래 추가:
```ts
  overlayTextColor: row.overlay_text_color ?? '#ffffff',
```

## 5단계: JournalScreen.tsx — 루틴카드 UI 수정

### 5-1. 날짜 형식 변경

루틴카드 헤더의 날짜 표시 부분을 찾는다:
```tsx
<Text style={det.routineCardDate}>{new Date(session.date).toLocaleDateString('en-US', { weekday: 'long', month: 'long', day: 'numeric', year: 'numeric' })}</Text>
```

변경 후 (PostWorkoutLogModal의 timestamp 포맷과 동일):
```tsx
<Text style={det.routineCardDate}>{(() => {
  const d = new Date(session.date);
  const pad = (n: number) => String(n).padStart(2, '0');
  const ENG_DAYS = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'];
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}(${ENG_DAYS[d.getDay()]})_${pad(d.getHours())}:${pad(d.getMinutes())}`;
})()}</Text>
```

### 5-2. 테두리 색상을 overlayTextColor 기반으로 변경

루틴카드 View의 style을 찾는다:
```tsx
style={det.routineCard}
```

변경 후:
```tsx
style={[det.routineCard, { borderColor: session.overlayTextColor ?? '#ffffff' }]}
```

### 5-3. 헤더에 부위 칩 추가

루틴카드 헤더 View를 찾는다:
```tsx
                  <View style={det.routineCardHeader}>
                    <Text style={det.routineCardGymName} numberOfLines={1}>{session.gymName}</Text>
                    <Text style={det.routineCardDate}>...</Text>
                  </View>
```

변경 후 (헬스장명 + 부위 칩을 한 줄에, 날짜는 아래):
```tsx
                  <View style={det.routineCardHeader}>
                    <View style={{ flexDirection: 'row', alignItems: 'center', justifyContent: 'space-between', marginBottom: 2 }}>
                      <Text style={[det.routineCardGymName, { flex: 1, marginRight: 8 }]} numberOfLines={1}>{session.gymName}</Text>
                      <View style={{
                        backgroundColor: session.overlayTextColor ?? '#ffffff',
                        borderRadius: 20,
                        paddingHorizontal: 10,
                        paddingVertical: 3,
                      }}>
                        <Text style={{
                          fontSize: 10,
                          fontWeight: '800',
                          color: '#000000',
                          letterSpacing: 0.5,
                          textTransform: 'uppercase',
                        }}>
                          {(() => {
                            const muscleCounts = machines.reduce<Record<string, number>>((acc, m) => {
                              acc[m.targetMuscle] = (acc[m.targetMuscle] ?? 0) + 1;
                              return acc;
                            }, {});
                            const sorted = Object.entries(muscleCounts)
                              .sort(([, a], [, b]) => b - a)
                              .map(([m]) => m);
                            return sorted.length > 1
                              ? sorted.slice(0, 2).join(' + ')
                              : `${sorted[0] ?? 'WORKOUT'}`;
                          })()}
                        </Text>
                      </View>
                    </View>
                    <Text style={det.routineCardDate}>{(() => {
                      const d = new Date(session.date);
                      const pad = (n: number) => String(n).padStart(2, '0');
                      const ENG_DAYS = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'];
                      return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}(${ENG_DAYS[d.getDay()]})_${pad(d.getHours())}:${pad(d.getMinutes())}`;
                    })()}</Text>
                  </View>
```

### 5-4. PR 뱃지 제거

루틴카드 내에서 PR 뱃지 렌더링 블록을 찾아서 제거한다:
```tsx
                              {isPR && (
                                <View style={det.exPRBadge}>
                                  <Text style={det.exPRTxt}>PR</Text>
                                </View>
                              )}
```
이 블록 전체를 삭제한다.

그리고 isPR 변수 선언도 사용되지 않으면 함께 제거한다:
```tsx
                    const isPR      = prMachines.has(m.machineId);
```
위 줄 제거.

`det.routineRowPR` 스타일 적용도 제거한다:
```tsx
                        <View style={[det.routineRow, isPR && det.routineRowPR]}>
```
변경 후:
```tsx
                        <View style={det.routineRow}>
```

### 5-5. routineCard 스타일에서 기본 borderColor 제거

기존:
```ts
  routineCard: { backgroundColor: '#FFFFFF', borderRadius: R.card, overflow: 'hidden', marginBottom: 20, borderWidth: 3, borderColor: C.border },
```

변경 후 (borderColor는 인라인으로 처리하므로 스타일에서 제거):
```ts
  routineCard: { backgroundColor: '#FFFFFF', borderRadius: R.card, overflow: 'hidden', marginBottom: 20, borderWidth: 3, borderColor: '#ffffff' },
```

## 주의사항

- 부위 칩의 텍스트 색상은 `#000000` 고정 (배경이 밝은 색/어두운 색 모두 대응하기 위해)
- overlayTextColor가 없는 기존 세션은 `#ffffff` 기본값으로 표시
- isPR 변수가 루틴카드 외 다른 곳에서도 사용되는지 확인 후 제거 여부 결정
- prMachines prop은 루틴카드 외 다른 UI에서 사용될 수 있으므로 prop 자체는 유지
