## 원인
GymPickLogo 컴포넌트는 style prop을 지원하지 않음.
transform은 감싸는 View에 적용해야 함.
좌측 로고는 세로로 긴 공간에 가로 로고를 회전시켜서 배치해야 함.

---

## STEP 1: 유형 A 좌측 로고 + 우측 하단 로고 블록 교체

`src/screens/flow/PostWorkoutLogModal.tsx` 에서
유형 A 블록 내부의 좌측 로고 View와 우측 하단 로고 View를 찾아서 교체한다.

### 좌측 세로 로고 찾는 코드:
```tsx
                    {/* 좌측 세로 GYM PICK 로고 */}
                    <View style={{
                      position: 'absolute',
                      left: 0,
                      top: 0,
                      bottom: 0,
                      width: 28,
                      alignItems: 'center',
                      justifyContent: 'center',
                    }}>
                      <View style={{ transform: [{ rotate: '180deg' }] }}>
                        <GymPickLogo color={tc} width={Math.round(LOGO_STRIP_H * 0.595)} height={Math.round(LOGO_STRIP_W * 0.595)} style={{ transform: [{ rotate: '-90deg' }] }} />
                      </View>
                    </View>
```

### 교체할 코드:
```tsx
                    {/* 좌측 세로 GYM PICK 로고 */}
                    <View style={{
                      position: 'absolute',
                      left: 0,
                      top: 0,
                      bottom: 0,
                      width: 28,
                      alignItems: 'center',
                      justifyContent: 'center',
                      overflow: 'hidden',
                    }}>
                      <View style={{ transform: [{ rotate: '-90deg' }] }}>
                        <GymPickLogo color={tc} width={Math.round(LOGO_STRIP_W * 0.595)} height={Math.round(LOGO_STRIP_H * 0.595)} />
                      </View>
                    </View>
```

---

### 우측 하단 로고 찾는 코드:
```tsx
                    {/* 우측 하단 세로 GYM PICK 로고 */}
                    <View style={{
                      position: 'absolute',
                      right: 4,
                      bottom: OVERLAY_PAD,
                      width: 28,
                      alignItems: 'center',
                    }}>
                      <View style={{ transform: [{ rotate: '-90deg' }] }}>
                        <GymPickLogo color={tc} width={Math.round(LOGO_STRIP_W * 0.595)} height={Math.round(LOGO_STRIP_H * 0.595)} />
                      </View>
                    </View>
```

### 교체할 코드:
```tsx
                    {/* 우측 하단 세로 GYM PICK 로고 */}
                    <View style={{
                      position: 'absolute',
                      right: 0,
                      bottom: OVERLAY_PAD * 2,
                      width: 28,
                      alignItems: 'center',
                      overflow: 'hidden',
                    }}>
                      <View style={{ transform: [{ rotate: '90deg' }] }}>
                        <GymPickLogo color={tc} width={Math.round(LOGO_STRIP_W * 0.595)} height={Math.round(LOGO_STRIP_H * 0.595)} />
                      </View>
                    </View>
```
