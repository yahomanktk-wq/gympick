BUG FIX: Duplicate machine IDs causing React rendering to skip filter updates
==================================================

ROOT CAUSE (confirmed from console logs):
src/data/machines.ts contains machines with duplicate IDs.
Examples found in logs:

  'nautilus_back_11' — appears 2+ times

When React renders a list with duplicate keys, it reuses the previous render
for duplicate-keyed items and skips updates — this is why filter changes
appear to have no effect even though filteredMachines is correctly computed.

Since there may be many duplicates, add a deduplication step at the end of machines.ts.

  const seenIds = new Map<string, number>()

  export const MACHINES: Machine[] = RAW_MACHINES.map(m => {
    if (!m.id) {
      const count = (seenIds.get('__blank__') ?? 0) + 1
      seenIds.set('__blank__', count)
      return {
        ...m,
        id: `${m.brand.toLowerCase().replace(/[\s/]+/g, '_')}_${m.targetMuscle.toLowerCase()}_auto_${count}`

    if (count === 1) return m
    return { ...m, id: `${m.id}_${String.fromCharCode(96 + count)}` }
  })
