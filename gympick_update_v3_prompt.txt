CHANGE 3: Workout logging flow redesign
==================================================

This is the most important and complex change.
Read the entire PostWorkoutLogModal.tsx carefully before making any changes.

CURRENT FLOW (what exists now):
  Step 1: Select gym
  Step 2: Select body part
  Step 3: Select machines (list or some other UI)
  Step 4: Log sets per machine
  Step 5: Complete

NEW FLOW (what we want):

The flow must be split based on which option the user chooses after selecting gym and body part.

--- PATH A: 새 루틴 작성하기 (New Routine) ---

After selecting gym + body part, user taps "새 루틴 작성하기".

Step A1: Machine Selection Screen
  Show all machines available in the selected gym that match the selected body part.
  Display each machine as a sports trading card (see SPORTS CARD SPEC below).
  Machines are NOT pre-selected. User taps a card to select one machine.
  Only ONE machine can be selected at a time on this screen.
  There is no "add all" button.
  At the bottom: "이 머신으로 운동 시작" button (disabled if no machine selected).

Step A2: Set Logging Screen (for the selected machine)
  Show the selected machine name and brand at the top.
  Show set input rows (weight kg + reps).
  User can add multiple sets.
  "저장하고 다음 머신" button at the bottom.
  Also "운동 종료" button to finish the entire session.

Step A3: After tapping "저장하고 다음 머신":
  Save the sets for this machine.
  Go back to Step A1 (Machine Selection Screen).
  The machine that was just logged should be visually marked as "완료" 
  (show a checkmark badge on its card or a different border color using C.accent).
  User selects the next machine.
  Repeat until user taps "운동 종료".

Step A4: On "운동 종료":
  Show workout summary screen.
  Ask "이 루틴을 저장할까요?" with Yes/No buttons.
  If Yes: show text input for routine name, then save routine (machine list only, no sets/weights).
  If No: skip saving routine.
  Then proceed to workout completion flow (existing photo/share screen if it exists).

--- PATH B: 이전 운동일지 참고하기 ---

After selecting gym + body part, user taps "이전 운동일지 참고하기".

Step B1: Show list of past workout logs from the same gym and same body part.
  Each item shows: date, list of machine names used.
  User taps one to select it as reference.

Step B2: Machine List Screen (pre-populated)
  Show the machines from the selected past log.
  Each machine displayed as sports trading card (see SPORTS CARD SPEC below).
  All machines are shown but none are checked yet.
  User can also add more machines or remove machines from the list.
  "운동 시작" button at the bottom.

Step B3: Set Logging - one machine at a time
  Show the first machine in the list.
  Show set input rows (weight kg + reps).
  Show previous best record for this machine if available (참고용 표시만, not auto-filled).
  "저장하고 다음 머신" button.
  "운동 종료" button.

Step B4: After each save, move to next machine in the list automatically.
  When all machines are done, or user taps "운동 종료", show completion screen.

--- PATH C: 헬스장 추천 루틴 ---

After selecting gym + body part, user taps "헬스장 추천 루틴".

Step C1: Show list of gym-recommended routines for this gym and body part.
  Each item shows: routine name, machine list preview.
  Use mock data if no real data exists.
  Example mock routine:
    Name: "파워 가슴 루틴"
    Machines: Chest Press, Incline Press, Cable Fly

Step C2: User taps a routine to select it.
  Show machine list pre-populated from the routine.
  Each machine displayed as sports trading card.
  User can add or remove machines.
  "운동 시작" button.

Step C3 onwards: Same as Path B Step B3 and B4.
  One machine at a time, set logging, save and move to next.

--- PATH D: 다른 유저 루틴 ---

After selecting gym + body part, user taps "다른 유저 루틴".

Step D1: Show list of routines shared by other users in the same gym.
  Each item shows: routine name (or anonymous user label), machine list preview.
  Use mock data if no real data exists.
  Example mock routine:
    Name: "익명 회원의 루틴"
    Machines: Lat Pulldown, Seated Row, Cable Row

Step D2: User taps a routine to select it.
  Show machine list pre-populated.
  Each machine displayed as sports trading card.
  User can add or remove machines.
  "운동 시작" button.

Step D3 onwards: Same as Path B Step B3 and B4.

--- ROUTE REFERENCE SCREEN (common entry point for B, C, D) ---

After selecting gym + body part, show a screen with 4 options as tappable cards:

  Card 1: 새 루틴 작성하기
    Icon: add-circle-outline
    Description: 이 헬스장 머신으로 직접 루틴을 만들어요

  Card 2: 이전 운동일지 참고하기
    Icon: time-outline
    Description: 지난 운동 기록을 참고해요

  Card 3: 헬스장 추천 루틴
    Icon: star-outline
    Description: 헬스장이 추천하는 루틴이에요

  Card 4: 다른 유저 루틴
    Icon: people-outline
    Description: 같은 헬스장 회원들의 루틴이에요

  Also a "건너뛰기" (skip) button at the bottom that goes directly to machine selection (Path A Step A1).

--- SPORTS CARD SPEC for machine selection screens ---

When showing machines as selectable cards in the machine selection screens,
use the same visual layout as the existing MachineCard component.
Do NOT modify MachineCard.tsx itself.
Instead, create a new component called SelectableMachineCard in src/components/SelectableMachineCard.tsx.

SelectableMachineCard props:
  machine: { id, name, brand, targetMuscle, category }
  selected: boolean
  completed: boolean (for Path A - already logged machines)
  onSelect: () => void

Visual spec:
  Base layout: identical to MachineCard (white background, black border, 9:16 ratio, top zone + image zone + info band + footer)
  Use GymPickLogo, brandLogos, getBrandCopyrightStatus same as MachineCard.
  
  When selected=true:
    Border color changes to C.accent (lime green)
    Border width: 3
    Show checkmark overlay in top-right corner: small circle with C.accent background and white checkmark icon

  When completed=true (Path A only):
    Show "완료" badge on the card
    Border color: C.accent with reduced opacity (C.accent + '80')
    Show green checkmark icon in top-right corner

  When neither: normal MachineCard appearance

  The entire card is a TouchableOpacity calling onSelect.
  No separate "선택" button.

Grid layout for machine selection:
  2 columns, gap 8, paddingHorizontal 16
  Same as existing machineGrid in FindGymScreen

--- SET LOGGING SCREEN SPEC ---

When logging sets for a single machine, show:

  Top section:
    Machine name (large, bold)
    Brand name (smaller, C.textSub)
    Target muscle pill badge

  Previous best section (if data exists):
    Label: "이전 최고 기록"
    Show the best set from past logs for this machine
    Style: C.textDim, smaller font, labeled as 참고용

  Set rows:
    Each set row: set number | weight input (kg) | reps input
    Default values: weight 0, reps 0
    "세트 추가" button to add another row
    Minimum 1 set row shown

  Bottom buttons:
    "저장하고 다음 머신" - saves sets and returns to machine selection
    "운동 종료" - ends entire session

  PR detection:
    If the logged weight x reps exceeds previous best, show "🎉 신기록!" badge
