## 2. PostWorkoutLogModal.tsx — 카메라 뷰파인더와 컨트롤 사이 간격 늘리기

카메라 뷰파인더(`cameraWrap`) 아래와 레이아웃 버튼+컬러칩 사이 간격을 늘린다.

WorkoutCameraOverlay를 감싸는 View 또는 container의 gap을 찾아서 수정한다.

### container gap 수정

WorkoutCameraOverlay.tsx의 container 스타일:

기존:
```tsx
  container: {
    alignItems: 'center',
    paddingHorizontal: 16,
    paddingTop: 8,
    gap: 12,
  },
```

변경 후 (gap 12→18):
```tsx
  container: {
    alignItems: 'center',
    paddingHorizontal: 16,
    paddingTop: 8,
    gap: 18,
  },
```

## 3. PostWorkoutLogModal.tsx — 컬러칩 크기 및 간격 축소

### colorChip 스타일 수정

기존:
```tsx
  colorChip: { width: 36, height: 36, borderRadius: 18, borderWidth: 2, borderColor: 'rgba(255,255,255,0.15)', marginRight: 14 },
```

변경 후 (width/height 36→28, borderRadius 18→14, marginRight 14→8):
```tsx
  colorChip: { width: 28, height: 28, borderRadius: 14, borderWidth: 2, borderColor: 'rgba(255,255,255,0.15)', marginRight: 8 },
```

### 레이아웃+컬러칩 한줄 블록에서 contentContainerStyle gap도 수정

레이아웃 버튼+컬러칩이 한 줄로 합쳐진 블록을 찾는다.
ScrollView의 contentContainerStyle에 gap이 있으면 줄인다:

기존:
```tsx
                contentContainerStyle={{ flexDirection: 'row', gap: 10, alignItems: 'center' }}
```

변경 후:
```tsx
                contentContainerStyle={{ flexDirection: 'row', gap: 6, alignItems: 'center', paddingRight: 8 }}
```
