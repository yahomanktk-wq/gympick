Fix the Google Play "Photo and Video Permissions" policy rejection (READ_MEDIA_IMAGES / READ_MEDIA_VIDEO) in the GymPick app.
Complete without stopping to ask for confirmation. Only report back when 100% complete.

==================================================
BACKGROUND (read first, do not skip)
==================================================

GymPick only WRITES generated 오운완 인증샷 images to the device gallery
(MediaLibrary.saveToLibraryAsync / createAssetAsync) and lets the user PICK an
existing photo from the gallery (ImagePicker.launchImageLibraryAsync). The app
never browses or reads the full gallery as a core feature. Google Play rejected
the app because the build declares READ_MEDIA_IMAGES / READ_MEDIA_VIDEO, which
are restricted permissions only allowed for apps whose core function requires
broad photo/video access.

Important fact: the "androidPermissions" key currently inside the
"expo-media-library" plugin config in app.json is NOT a real supported option
for that plugin (it is silently ignored). It must be removed and replaced with
a working mechanism (expo-build-properties' android.blockedPermissions).

This is a 4-part fix. Do all 4 parts. Do not skip part 4 (codebase-wide check).

      "savePhotosPermission": "운동 완료 카드 이미지를 사진 앱에 저장하기 위해 접근이 필요합니다.",
      "isAccessMediaLocationEnabled": true
    }
  ]

Step 2c — Add a new "expo-build-properties" plugin entry to the "plugins"
array (anywhere in the array, e.g. right after "expo-image-picker"). This is
the mechanism that actually strips the restricted permissions from the final
merged AndroidManifest.xml regardless of which library (expo-media-library or
expo-image-picker) declares them:

  [
    "expo-build-properties",
    {
      "android": {
        "blockedPermissions": [
          "android.permission.READ_MEDIA_IMAGES",
          "android.permission.READ_MEDIA_VIDEO"
        ]
      }
    }
  ]

Do NOT block READ_EXTERNAL_STORAGE or WRITE_EXTERNAL_STORAGE — those are not
restricted by this policy and are still needed for older Android versions.
