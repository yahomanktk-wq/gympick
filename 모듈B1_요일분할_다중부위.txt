■ 작업 개요
분할 루틴 "요일 기반"에서 하루에 부위 2개 이상 설정 가능하게 한다.
요일 기반 데이터는 이미 배열(string[]/요일)이라, 설정 화면의 "인위적 1개 제한"을
풀고 + 읽기 함수(splitUtils)를 배열 반환으로 확장하면 된다.
(순서 기반 구조 변경은 다음 단계 B2에서 진행 — 이번엔 건드리지 않음)

■ 핵심 설계
- splitUtils에 배열 반환 함수(getTodayTargets/isRestToday/getNextTargets/
  collectRoutineMuscles)를 "추가"한다. 기존 getTodayTarget/getNextTarget는
  남겨둔다(HomeScreen이 아직 사용 → 깨지지 않게).
- 순서 기반은 이번 단계에서 여전히 string[]로 취급(B2에서 string[][]로 변경).
- 분할 부위명은 한글('가슴','등'...)로 저장됨. selectedMuscles는 영어명.
  → 프리로드에서 toEnMuscle로 변환해 채운다.

[파일 1] src/lib/splitUtils.ts — 배열 반환 API 추가
================================================================================
기존 함수(getTodayTarget, getNextTarget, calcNextIndex, extractCompletedTargets,
toKoMuscle, toEnMuscle 등)는 그대로 두고, 아래 블록을 모듈 레벨에 추가한다.
(DAY_KEYS 상수가 이미 파일에 있으므로 그대로 사용. SequentialSplit 타입도 이미 import됨)

추가할 코드:

  // ── 다중 타겟부위 지원 API (배열 반환) ─────────────────────────────────
  // 부위 배열에서 '휴식'/빈값 제외
  function workoutMusclesOf(muscles: string[]): string[] {
    return muscles.filter(m => !!m && m !== '휴식');
  }

  // 오늘의 운동 부위들 (휴식/미설정이면 빈 배열). 한글 부위명.
  export function getTodayTargets(
    splitType: SplitType,
    workoutSplit: WorkoutSplit,
    splitCurrentIndex: number
  ): string[] {
    if (!workoutSplit || (Array.isArray(workoutSplit) && workoutSplit.length === 0)) return [];

    if (splitType === 'weekday') {
      const split = workoutSplit as WeekdaySplit;
      const dayKey = DAY_KEYS[new Date().getDay()];
      return workoutMusclesOf((split[dayKey] ?? []) as string[]);
    }

    // B1: 순서 기반은 아직 string[] (B2에서 string[][]로 변경)
    const split = workoutSplit as SequentialSplit;
    if (split.length === 0) return [];
    const t = split[splitCurrentIndex % split.length];
    return t && t !== '휴식' ? [t] : [];
  }

  // 오늘이 명시적 휴식인지
  export function isRestToday(
    splitType: SplitType,
    workoutSplit: WorkoutSplit,
    splitCurrentIndex: number
  ): boolean {
    if (!workoutSplit) return false;

    if (splitType === 'weekday') {
      const split = workoutSplit as WeekdaySplit;
      const dayKey = DAY_KEYS[new Date().getDay()];
      const m = (split[dayKey] ?? []) as string[];
      return m.length > 0 && workoutMusclesOf(m).length === 0;
    }

    const split = workoutSplit as SequentialSplit;
    if (split.length === 0) return false;
    return split[splitCurrentIndex % split.length] === '휴식';
  }

  // 루틴 전체 부위 모으기 (배너의 "루틴 부위 했나" 판정용)
  export function collectRoutineMuscles(
    splitType: SplitType,
    workoutSplit: WorkoutSplit
  ): string[] {
    if (splitType === 'sequential') {
      return ((workoutSplit as SequentialSplit) ?? []).filter(m => m !== '휴식');
    }
    const wd = workoutSplit as WeekdaySplit;
    return DAY_KEYS.flatMap(k => (wd[k] ?? []) as string[]).filter(m => m !== '휴식');
  }

  // 다음 운동 부위들 (완료 제외, 휴식 건너뜀)
  export function getNextTargets(
    splitType: SplitType,
    workoutSplit: WorkoutSplit,
    splitCurrentIndex: number,
    completedTargets: string[]
  ): string[] {
    if (!workoutSplit || (Array.isArray(workoutSplit) && workoutSplit.length === 0)) return [];
    const done = completedTargets.map(t => t.toLowerCase());

    if (splitType === 'sequential') {
      const split = workoutSplit as SequentialSplit;
      let idx = splitCurrentIndex, checked = 0;
      while (checked < split.length) {
        const t = split[idx % split.length];
        if (t === '휴식') { idx++; checked++; continue; }
        if (!done.includes(t.toLowerCase())) return [t];
        idx++; checked++;
      }
      return [];
    }

    const split = workoutSplit as WeekdaySplit;
    const todayIdx = new Date().getDay();
    for (let i = 1; i <= 7; i++) {
      const dayKey = DAY_KEYS[(todayIdx + i) % 7];
      const work = workoutMusclesOf((split[dayKey] ?? []) as string[]);
      if (work.length > 0) return work;
    }
    return [];
  }

function getSplitBannerMessage(
  splitConfig: UserSplitConfig | null,
  todaySessions: WorkoutLog[]
): { message: string; sub?: string } | null {
  if (!splitConfig) return null;
  const split = splitConfig.workoutSplit;
  if (!split || (Array.isArray(split) && split.length === 0)) return null;

  const todayTargets = getTodayTargets(
    splitConfig.splitType,
    split,
    splitConfig.splitCurrentIndex
  );
  const rest = isRestToday(
    splitConfig.splitType,
    split,
    splitConfig.splitCurrentIndex
  );

  if (rest) {
    return { message: '오늘은 휴식 Day예요 🛌' };
  }

  const todayStr = todayTargets.join('·');

  if (todaySessions.length === 0) {
    return todayTargets.length > 0
      ? { message: `오늘은 ${todayStr} Day예요 💪` }
      : null;
  }

  const completedTargets = extractCompletedTargets(todaySessions.flatMap(s => s.machines));
  const nextTargets = getNextTargets(
    splitConfig.splitType,
    split,
    splitConfig.splitCurrentIndex,
    completedTargets

  const routineTargets = collectRoutineMuscles(splitConfig.splitType, split);
  const completedRoutine = completedTargets.filter(t =>
    routineTargets.includes(t) && t !== '휴식'
  );

  if (completedRoutine.length > 0) {
    const completedStr = completedRoutine.join(' + ');
    if (nextTargets.length > 0) {
      return { message: `오늘 ${completedStr} 완료! 🔥`, sub: `다음은 ${nextStr} Day예요` };
    }
    return { message: `오늘 ${completedStr} 완료! 🔥` };
  }

  const completedStr = completedTargets.filter(t => t !== '휴식').join(' + ');
  return {
    message: `오늘은 ${completedStr} 운동 했군요!`,
    sub: todayTargets.length > 0 ? `${todayStr} Day는 다음 운동 때 해요` : undefined,
  };
