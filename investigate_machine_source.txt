MACHINES를 직접 import해서 쓰기 때문으로 추정된다.
목표: 어드민/매니저도 '찾기 화면과 동일하게' Supabase 머신 데이터를 읽도록 전환하기 위한

[조사 5] 비동기 전환 시 고려사항
================================================================================
로컬 MACHINES는 동기(import 즉시 사용), Supabase는 비동기(fetch 필요).
- 어드민/매니저에서 MACHINES가 '모듈 레벨 상수'(파일 최상위)로 쓰이는 곳이 있는지
  (예: const CAT_BRANDS = [...MACHINES...] — 이건 컴포넌트 밖이라 async 불가)
- 이런 곳들을 컴포넌트 내부 state로 옮겨야 하는지 판단
- 찾기 화면은 이 비동기 로딩을 어떻게 처리하는지 (로딩 상태, useEffect 등)

[분석]
- 비동기 전환 시 구조 변경이 필요한 지점 (모듈 상수 → state)
- 로딩 중 UI 처리 방식 (찾기 화면 참고)
