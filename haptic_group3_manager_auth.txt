# 태스크: 햅틱 추가 — 그룹 3 (매니저 대시보드 & 인증 플로우)

## 대상 파일
- src/screens/manager/ManagerDashboard.tsx
- src/screens/auth/AuthFlow.tsx

## 공통 규칙
1. 각 파일 상단에 `import * as Haptics from 'expo-haptics';` 가 없으면 추가
2. 이미 Haptics 호출이 있는 버튼은 스킵
3. disabled 상태 버튼에는 추가하지 않음
4. Switch 컴포넌트에는 추가하지 않음
5. 햅틱은 onPress 핸들러 첫 줄에 추가

## 강도 기준
- `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light)`
  → 일반 탭, 목록 항목, 탭 전환, 필터
- `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium)`
  → 저장, 확인, 제출, 로그인/회원가입 CTA, 승인
- `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Heavy)`
  → 삭제, 거절, 경고성 액션

## 파일별 적용 대상

### ManagerDashboard.tsx
- 탭 전환 버튼 → Light
- 헬스장 정보 수정 저장 버튼 → Medium
- 머신 추가 버튼 → Medium
- 머신 삭제 버튼 → Heavy
- 공지 작성 저장 버튼 → Medium
- 공지 삭제 버튼 → Heavy
- 수정 요청 제출 버튼 → Medium
- 뒤로가기/닫기 버튼 → Light
- 목록 항목 탭 → Light
- 루틴 저장 버튼 → Medium
- 루틴 삭제 버튼 → Heavy

### AuthFlow.tsx
- 로그인 버튼 (CTA) → Medium
- 회원가입 버튼 (CTA) → Medium
- 소셜 로그인 버튼 (Google, Apple, Kakao) → Medium
- 비밀번호 찾기 버튼 → Light
- 약관 동의 체크박스/버튼 → Light
- 뒤로가기 버튼 → Light
- 이메일/비밀번호 입력 완료 후 다음 버튼 → Medium
- 탭 전환 (로그인 ↔ 회원가입) → Light

## 적용 방법 예시
```tsx
// 변경 전
<TouchableOpacity onPress={handleLogin}>

// 변경 후
<TouchableOpacity onPress={() => {
  Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium);
  handleLogin();
}}>

// Alert 포함 케이스
// 변경 전
<TouchableOpacity onPress={() => {
  Alert.alert('삭제', '삭제하시겠어요?', [...]);
}}>

// 변경 후
<TouchableOpacity onPress={() => {
  Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Heavy);
  Alert.alert('삭제', '삭제하시겠어요?', [...]);
}}>
```

## 주의사항
- 기존 onPress 로직을 절대 변경하지 말 것 (햅틱 한 줄만 추가)
- 파일 내 다른 코드(스타일, 상태, 로직) 일절 건드리지 말 것
- 타입스크립트 에러 없을 것
