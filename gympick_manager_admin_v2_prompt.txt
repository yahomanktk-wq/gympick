BUG FIX 1: Text input only accepts one character at a time
==================================================

PROBLEM:
In the gym registration form (ManagerDashboard.tsx and related step components),
TextInput fields only accept one character at a time.
The user must tap repeatedly to enter consecutive characters.
This is caused by improper state update pattern causing re-renders.

FIX:
Step 1: Find every TextInput in the gym registration form steps.

Step 2: For every onChangeText handler that updates a state object, change to functional update:
  WRONG:
    onChangeText={(text) => setFormData({ ...formData, gymName: text })}
  CORRECT:
    onChangeText={(text) => setFormData(prev => ({ ...prev, gymName: text }))}

Step 3: Add these props to every TextInput in the registration form:
  autoCorrect={false}
  autoCapitalize="none"
  spellCheck={false}

Step 4: If the form uses useCallback or useMemo for handlers, make sure
  the dependency arrays are correct and not causing unnecessary re-renders.

Step 5: Also check if the parent component re-renders on every keystroke
  due to state being lifted too high. If so, consider using useRef for
