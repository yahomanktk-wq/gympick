제조사 시리즈 프리셋

버튼을 누르면 시리즈 머신 카드가 이미지와 함께 한 번에 만들어져요. 부위·카테고리는 미리 채워져 있으니 확인만 하세요.
이미지 파일을 여기에 끌어다 놓거나
미리캔버스에서 편집을 마친 이미지를 넣으세요. 이미지마다 브랜드·부위·카테고리를 고르면 ID가 자동으로 붙어요.
· ID 규칙: 브랜드_부위_번호 (예: panatta_chest_54). 지금 DB에 있는 같은 접두사의 가장 큰 번호 다음부터 매겨요.
· 타겟부위는 먼저 고른 것이 주 부위(①)예요. 카테고리도 고른 순서대로 저장돼요.
· 어드민 로그인 후에는 카드마다 DB에 바로 등록(이미지 업로드 → 머신 등록 → 신청 헬스장 연결 → 신청 처리 → 매니저 알림)을 할 수 있어요. 신청 카드는 편집한 이미지를 카드 사진 위에 끌어다 놓으면 바뀌어요.
· 로그인 없이도 예전처럼 CSV + 이미지(zip)를 받아서 직접 올릴 수 있어요. 이미지는 800×800 흰 배경 webp, 파일명은 ID로 바뀌어 있어요.
