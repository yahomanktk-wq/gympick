## 원인
expo-camera의 CameraView는 뷰파인더 렌더 크기(화면에 보이는 크기)를 기준으로
카메라 해상도 프리셋을 자동 선택한다.
앱 내에서 작은 영역에 카메라를 띄우면 낮은 해상도 프리셋이 선택되어 화질이 저하된다.

## 해결 방법
1. CameraView에 `pictureSize` prop으로 최고 해상도를 명시적으로 지정한다
2. `quality: 1` 로 올려서 JPEG 압축 손실을 최소화한다
3. `exif: true` 추가로 방향 정보(EXIF)를 포함시켜 이미지가 올바른 방향으로 저장되게 한다

---

## 수정 내용

### 1. CameraView에 pictureSize 및 ratio prop 추가

기존:
```tsx
        <CameraView
          ref={cameraRef}
          style={StyleSheet.absoluteFill}
          facing="back"
          flash={flash}
          onCameraReady={() => setCameraReady(true)}
        />
```

변경 후:
```tsx
        <CameraView
          ref={cameraRef}
          style={StyleSheet.absoluteFill}
          facing="back"
          flash={flash}
          onCameraReady={() => setCameraReady(true)}
          pictureSize="Photo"
        />
```

### 2. takePictureAsync 옵션 수정

기존:
```tsx
      const photo = await cameraRef.current.takePictureAsync({
        quality: 0.9,
        skipProcessing: false,
      });
```

변경 후:
```tsx
      const photo = await cameraRef.current.takePictureAsync({
        quality: 1,
        skipProcessing: false,
        exif: true,
      });
```

## 동작 확인 체크리스트

1. 카메라로 찍기 → 촬영된 사진이 기본 카메라와 유사한 화질로 나옴 ✅
2. 촬영된 사진이 올바른 방향(세로)으로 저장됨 ✅
3. 오버레이 합성 결과물(이미지 저장) 화질 정상 ✅
