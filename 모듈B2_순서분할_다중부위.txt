[모듈 B2] 분할 루틴 — 순서 기반 하루 2개 이상 (string[][] 구조 변경)
================================================================================

■ 작업 개요
순서 기반 분할을 "슬롯당 부위 1개(string[])"에서 "슬롯당 부위 여러 개(string[][])"로
바꾼다. 한 슬롯 = 하루(운동 1회) = 부위 여러 개.
  - UI: 방식 1 (순서 추가 버튼 → 각 슬롯 안에서 부위 칩 토글)
  - 완료 판정: 느슨함 (슬롯 부위 중 하나라도 운동하면 그 슬롯 완료로 보고 다음으로)
  - 마이그레이션: 기존 ['가슴','등','하체'] → [['가슴'],['등'],['하체']]

■ 핵심 설계
- SequentialSplit 타입을 string[] → string[][]로 변경. 이 한 줄이 tsc로
  순차 분기 누락 지점을 전부 에러로 잡아준다 → 아래 모든 PART를 적용하면 0건이 됨.
- 분할 부위명은 한글('가슴','등'). '휴식'은 슬롯에 '휴식'만 든 경우.
- splitUtils의 단일 함수(getTodayTarget/getNextTarget)는 복수 함수의 [0] 래퍼로
  단순화 (HomeScreen이 getTodayTarget을 아직 사용 → 깨지지 않게).
- SQL 없음 (workout_split은 JSON이라 string[][] 그대로 저장됨).

■ 변경 파일 (6개)

  function migrateLegacySequentialSplit(raw: any): string[][] {
    if (!Array.isArray(raw)) return [];
    return raw
      .map((item: any) => {
        if (Array.isArray(item)) return item.filter((x: any) => typeof x === 'string');
        if (typeof item === 'string') return item ? [item] : [];
        return [];
      })
      .filter((slot: string[]) => slot.length > 0);
  }

export function getNextTarget(
  splitType: SplitType,
  workoutSplit: WorkoutSplit,
  splitCurrentIndex: number,
  completedTargets: string[]
): string | null {
  if (!workoutSplit || (Array.isArray(workoutSplit) && workoutSplit.length === 0)) return null;

  if (splitType === 'sequential') {
    const split = workoutSplit as SequentialSplit;
    let idx = splitCurrentIndex;
    let checked = 0;
    while (checked < split.length) {
      const target = split[idx % split.length];
      if (target === '휴식') { idx++; checked++; continue; }
      if (!completedTargets.map(t => t.toLowerCase()).includes(target.toLowerCase())) return target;
      idx++;
      checked++;
    }
    return null;
  }

  const split = workoutSplit as WeekdaySplit;
  const todayIdx = new Date().getDay();
  for (let i = 1; i <= 7; i++) {
    const dayKey = DAY_KEYS[(todayIdx + i) % 7];
    const targets = (split[dayKey] ?? []) as string[];
    const nonRest = targets.filter(t => t !== '휴식');
    if (nonRest.length > 0) return nonRest[0];
  }
  return null;
}

NEW:
export function calcNextIndex(
  workoutSplit: SequentialSplit,   // string[][]
  currentIndex: number,
  completedTargets: string[]
): number {
  const len = workoutSplit.length;
  if (len === 0) return 0;
  const done = completedTargets.map(t => t.toLowerCase());
  let idx = currentIndex;
  let advanced = 0;
  while (advanced < len) {
    const slot = workoutSplit[idx % len] ?? [];
    const work = workoutMusclesOf(slot);
    if (work.length === 0) { idx++; advanced++; continue; }          // 휴식/빈 슬롯 건너뜀
    const slotDone = work.some(m => done.includes(m.toLowerCase()));
    if (!slotDone) break;                                            // 아직 안 한 슬롯에서 멈춤
    idx++;
    advanced++;
  }
  return idx % len;
}
