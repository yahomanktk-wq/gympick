STEP 2 — Add a shuffle helper (module level)

Add this near the top of the file, at module level (alongside other module-level

    function shuffleMachines<T>(arr: T[]): T[] {
      const result = [...arr];
      for (let i = result.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        [result[i], result[j]] = [result[j], result[i]];
      }
      return result;
    }

(Standard Fisher-Yates shuffle, non-mutating — takes a copy so `allMachines`
itself is never mutated.)
