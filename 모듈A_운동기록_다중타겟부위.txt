================================================================================
[모듈 A] 운동 기록 - 타겟부위 2개 이상 저장/표시 (경로 2)
================================================================================

■ 작업 개요
운동을 기록할 때 사용자가 선택한 타겟부위(selectedMuscles)를 세션에 직접 저장하고
(현재는 저장 안 됨 → 머신에서 역산), 인증샷/홈/운동일지가 그 저장값을 읽어
부위 2개 이상을 끝에서 끝까지 표시하도록 수정한다.

■ 핵심 설계 원칙 (꼭 지킬 것)
1) 부위 표준화(예: 'Hip (Glutes)' → 'Glutes')는 **저장 직전 한 곳(PostWorkoutLogModal)**
   에서만 한다. DB/홈/일지는 표준값을 "읽기만" 한다.
2) 선택·머신필터에 쓰이는 prop은 **절대 건드리지 않는다** (그룹 라벨 그대로여야 필터 동작).
   → PostWorkoutLogModal 4076번/4102번 줄의 selectedMuscles prop은 변경 금지.
3) 기존(옛) 세션은 새 컬럼이 비어 있으므로 → 머신에서 역산한 값으로 fallback (옛 기록 안 깨짐).
4) 부위 3개 이상이면 '가슴 + 등 + 어깨'처럼 전부 이어붙인다 (2개 cap 제거).

--------------------------------------------------------------------------------
⚠ 사전 필수 (코드 적용 전에 사람이 직접 실행) : Supabase SQL Editor
--------------------------------------------------------------------------------
아래 SQL을 Supabase SQL Editor에서 **먼저** 실행해야 한다.
(코드가 target_muscles 컬럼을 SELECT 하는데, 컬럼이 없으면 쿼리가 에러나고
 mock 데이터로 fallback 되어 실제 세션이 안 보이게 됨)

  ALTER TABLE workout_sessions
    ADD COLUMN IF NOT EXISTS target_muscles text[];

※ Claude Code는 이 SQL을 실행하지 말 것. 코드 수정만 진행한다.
  (사용자가 별도로 Supabase에서 실행함)
