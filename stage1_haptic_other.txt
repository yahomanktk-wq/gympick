[파일 1] src/screens/FindGymScreen.tsx — 햅틱 Light → Medium
================================================================================
이 파일에서 햅틱 강도를 모두 Medium으로 통일한다.
FindGymScreen.tsx 안의 모든

    Haptics.ImpactFeedbackStyle.Light

를

    Haptics.ImpactFeedbackStyle.Medium

으로 바꾼다. (해당 파일 내 전부 — 탭 4개, 리스트/지도 토글, 부위/카테고리/브랜드
필터 칩, 검색 X 버튼, 헬스장 등록요청 버튼 등 조사에서 확인된 모든 위치)

방법:
- FindGymScreen.tsx 파일만 대상으로, 문자열 'ImpactFeedbackStyle.Light' 를
  'ImpactFeedbackStyle.Medium' 으로 일괄 치환.
- 다른 파일은 건드리지 말 것 (FindGymScreen.tsx만).
- 치환 후, 파일 내에 'ImpactFeedbackStyle.Light' 가 0건 남았는지 확인.

참고(조사에서 확인된 위치, 모두 Light→Medium 대상):
  L568, L575, L582, L589 (탭 4개)
  L788, L796 (리스트/지도)
  L613 (검색 X)
  L639 (부위 필터)
  L662, L685 (카테고리 필터)
  L131 (브랜드 필터 FilterRow)
  L838 (헬스장 등록요청 버튼)
  ※ 줄 번호는 참고용. 실제로는 'ImpactFeedbackStyle.Light' 전부를 Medium으로.

================================================================================
[파일 2] src/screens/flow/PostWorkoutLogModal.tsx — matchesMuscle에 'Other' 추가
================================================================================
어느 부위를 선택하든 targetMuscle='Other' 머신이 항상 포함되도록 한 줄 추가.

OLD:
  function matchesMuscle(targetMuscle: string): boolean {
    if (selectedMuscles.has(targetMuscle)) return true;
    if (targetMuscle === 'Glutes' && selectedMuscles.has('Hip (Glutes)')) return true;
    if (targetMuscle === 'Glutes' && selectedMuscles.has('Leg')) return true;
    return false;
  }
NEW:
  function matchesMuscle(targetMuscle: string): boolean {
    if (selectedMuscles.has(targetMuscle)) return true;
    if (targetMuscle === 'Glutes' && selectedMuscles.has('Hip (Glutes)')) return true;
    if (targetMuscle === 'Glutes' && selectedMuscles.has('Leg')) return true;
    if (targetMuscle === 'Other') return true;
    return false;
  }

  ※ 이 한 줄로, 부위를 1개 이상 선택한 상태에서 머신 목록에 'Other' 머신이
    항상 함께 노출된다. (selectedMuscles가 비어있을 때의 동작은 기존 로직을 따르며
    이 변경으로 달라지지 않음 — matchesMuscle은 부위 선택 후 필터에만 쓰임)
