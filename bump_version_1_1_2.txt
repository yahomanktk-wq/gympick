================================================================================
[버전업] app.json 버전 1.1.1 → 1.1.2
================================================================================

■ 목적
iOS App Store 제출 시 '1.1.x 트레인 닫힘/중복' 문제를 피하기 위해 앱 버전을 올린다.
EAS autoIncrement 설정 여부와 무관하게 안전하도록 version/buildNumber/versionCode를 모두 올린다.

■ 변경 파일 (1개)
  app.json

⚠ 아래 3개 값만 변경. 다른 필드는 절대 건드리지 말 것.
⚠ JSON 문법 유지 (쉼표/따옴표). buildNumber는 문자열, versionCode는 정수인 점 주의.

================================================================================
[변경 1] version 1.1.1 → 1.1.2
================================================================================
OLD:
    "version": "1.1.1",
NEW:
    "version": "1.1.2",

================================================================================
[변경 2] ios.buildNumber "29" → "30"
================================================================================
OLD:
      "buildNumber": "29",
NEW:
      "buildNumber": "30",

================================================================================
[변경 3] android.versionCode 11 → 12
================================================================================
OLD:
      "versionCode": 11,
NEW:
      "versionCode": 12,

================================================================================
■ 완료 후 자체 점검
================================================================================
1) app.json이 유효한 JSON인지 (파싱 에러 없는지)
2) version "1.1.2", buildNumber "30"(문자열), versionCode 12(정수)로 변경됨
3) 그 외 필드 변경 없음
4) npx tsc --noEmit (app.json은 타입체크 대상 아니지만, 다른 변경 없었는지 확인차)

■ 참고
- EAS eas.json에 autoIncrement가 켜져 있으면 빌드 시 buildNumber/versionCode가
  서버에서 자동 증가하므로 app.json 값은 무시될 수 있음. 그래도 올려두면 무해.
- iOS 트레인 문제의 핵심은 version(1.1.x)이므로 1.1.2로 올리면 해결됨.
================================================================================
