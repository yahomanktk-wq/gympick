# 목적

앱 버전을 1.2.0으로 업데이트한다. 오늘 작업한 코드 변경(이미지 로딩 성능 개선,
MachineCard 머신명 정렬 수정, 운동일지 머신/프리웨이트 카테고리 토글 추가)은 이미
각각 개별 커밋으로 완료되어 있으므로, 이번 작업은 버전 정보만 수정하고 커밋한다.

## 작업 순서

### 1단계 — 버전 설정 파일 확인

`app.json` 또는 `app.config.js`/`app.config.ts` 중 실제로 프로젝트에서 쓰이는 파일을
`view`로 찾아서 연다 (둘 다 있다면 Expo가 실제로 읽는 우선순위를 따른다 — 보통
`app.config.js`/`app.config.ts`가 있으면 그쪽이 우선). 그 안에서 다음 값들을 찾는다:

- `expo.version` (예: "1.1.3" 같은 semver 문자열)
- `expo.ios.buildNumber` (문자열, 보통 "1" 같은 정수 문자열)
- `expo.android.versionCode` (숫자, 정수)

현재 값을 그대로 보고한다.

### 2단계 — 버전 값 수정

- `expo.version`을 `"1.2.0"`으로 변경한다.
- `expo.ios.buildNumber`를 현재 값에서 1 증가시킨 문자열로 변경한다
  (예: 현재 "12"면 "13"으로).
- `expo.android.versionCode`를 현재 값에서 1 증가시킨 정수로 변경한다
  (예: 현재 12면 13으로).
- 이 세 값 외의 다른 어떤 설정도 건드리지 않는다.

### 3단계 — package.json 버전도 확인

`package.json`의 최상위 `"version"` 필드가 있다면, 그 값도 `"1.2.0"`으로 맞춰서
동일하게 변경한다. 없다면 건드리지 않는다.

## 검증 절차 (필수, 순서대로)

1. `git diff` 로 변경된 파일과 내용을 확인한다. 버전 관련 필드(version, buildNumber,
   versionCode) 외에 다른 값이 실수로 바뀌지 않았는지 반드시 확인한다.
2. 문제 없으면 변경된 버전 관련 파일들을 커밋한다:
   `git add app.json`(또는 실제 파일명) `package.json`(있는 경우)
   커밋 메시지: `chore: 버전 1.2.0으로 업데이트 (버전코드/빌드번호 증가 포함)`

## 완료 후 안내 (실행하지 말고 보고만 할 것)

작업이 끝나면 다음 내용을 요약으로 보고한다:
- 변경 전/후 버전, buildNumber, versionCode 값
- "git push와 EAS 빌드/제출은 태경님이 직접 실행해야 합니다"라는 안내

## 중단 조건

- `app.json`/`app.config.js`/`app.config.ts` 어디에서도 `version`,
  `ios.buildNumber`, `android.versionCode` 값을 찾을 수 없는 경우 → 실제 파일
  구조를 그대로 보고하고 중단

## 절대 금지

- 버전 관련 필드(version, buildNumber, versionCode) 외의 다른 설정/코드는 절대
  수정하지 마세요
- `eas build`, `eas submit` 등 EAS 관련 명령어를 절대 실행하지 마세요 (버전 파일
  수정과 커밋까지만 하는 작업입니다)
- `git push` 절대 실행하지 마세요
