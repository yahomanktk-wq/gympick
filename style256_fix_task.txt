## STEP 2: LeftColOverlay (스타일 2) 타겟부위 크기 10% 증가

`LeftColOverlay` 함수 내부에서 muscleLabel을 렌더링하는 Text를 찾는다.

현재 fontSize가 22인 부분을 찾아서 24로 변경한다 (22 × 1.1 ≈ 24):

찾는 코드:
```tsx
style={{
  fontSize: 22,
  fontWeight: '900',
  color: tc,
  letterSpacing: -0.5,
  fontFamily: 'QuicksilverItalic',
}}
```

변경 후:
```tsx
style={{
  fontSize: 24,
  fontWeight: '900',
  color: tc,
  letterSpacing: -0.5,
  fontFamily: 'QuicksilverItalic',
}}
```

## STEP 3: LeftColOverlay (스타일 2) 하단우측 로고 20% 축소

`LeftColOverlay` 함수 내부에서 우하단 GymPickLogo를 찾는다.
우하단 로고는 `bottom: OVERLAY_PAD, right: OVERLAY_PAD` 위치에 있다.

찾는 코드:
```tsx
<GymPickLogo color={tc} width={Math.round(LOGO_STRIP_W * 0.85)} height={Math.round(LOGO_STRIP_H * 0.85)} />
```

`0.85` 를 `0.68` 로 변경한다 (0.85 × 0.8 = 0.68):
```tsx
<GymPickLogo color={tc} width={Math.round(LOGO_STRIP_W * 0.68)} height={Math.round(LOGO_STRIP_H * 0.68)} />
```

NOTE: LeftColOverlay 안에 로고가 여러 개 있을 수 있으니
`bottom: OVERLAY_PAD, right: OVERLAY_PAD` 위치의 로고만 변경한다.

## STEP 4: SidebarOverlay (스타일 5) 타겟부위 잘림 수정

`SidebarOverlay` 함수 내부에서 muscleLabel 세로 회전 텍스트를 찾는다.
`transform: [{ rotate: '90deg' }]` 가 포함된 Text 이다.

현재 `width: photoH * 0.35` 로 설정되어 있어서 긴 텍스트가 잘림.
아래와 같이 수정한다:

- `width` 를 `photoH * 0.35` → `photoH * 0.55` 로 증가
- `numberOfLines={1}` 이 있으면 제거
- `adjustsFontSizeToFit` 와 `minimumFontScale` 추가로 긴 텍스트 자동 축소 대응

최종 muscleLabel Text 스타일:
```tsx
<Text style={{
  fontSize: 26,
  fontWeight: '900',
  color: tc,
  transform: [{ rotate: '90deg' }],
  width: photoH * 0.55,
  textAlign: 'center',
  letterSpacing: -0.3,
  fontFamily: 'SportypoReguler',
}} adjustsFontSizeToFit minimumFontScale={0.5}>
  {muscleLabel}
</Text>
```

## STEP 7: TopBigOverlay (스타일 6) 구분선 제거

`TopBigOverlay` 함수 내부에서 구분선 View를 찾아서 제거한다.

찾는 코드:
```tsx
{/* 구분선 */}
<View style={{ height: 1.5, backgroundColor: tc, marginTop: 10, opacity: 0.5 }} />
```

위 View 를 완전히 삭제한다.

구분선 주석이 없을 경우 `height: 1.5` 와 `backgroundColor: tc` 를 동시에 가진
View 를 찾아서 삭제한다.
