be able to attach a short text comment explaining their decision. The
requesting user should then be able to see that comment via the app's existing
notification feature.

   manager-submitted

3. 정보 수정 요청 (edit requests — both editList/RegEditRequest and legacy
   pendingEdits if both are still actively used — confirm which is actually
   live in Step 1)
4. 정보 제보 (gym info reports / gymReportStore)
