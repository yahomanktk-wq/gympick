아래 기획 문서를 기반으로 GymPick 앱에 새 기능을 추가해줘.

## 핵심 규칙 (절대 변경 금지)
- 운동 기록은 반드시 사용자가 세트를 수행한 후에 입력한다
- 루틴에서 세트/중량을 자동 입력하지 않는다
- 기존 PostWorkoutLogModal, 세트 기록 UI, PR 감지 로직은 건드리지 않는다
- 기존 컬러 시스템(C, R, T theme), 네비게이션, MachineCard는 수정하지 않는다

## 구현 방식
- 새 파일을 추가하는 방식으로 작업한다
- 기존 파일은 최소한으로만 수정한다
- 한 번에 전부 구현하지 말고, 아래 순서대로 하나씩 진행한다
- 각 단계 완료 후 내가 확인하면 다음 단계로 넘어간다

## 기획 문서

### 루틴 참고 화면
운동 생성 중 헬스장 선택 → 부위 선택 직후에 루틴 참고 화면이 나타난다.
루틴 참고 화면은 아래 4개 섹션을 포함한다.

**섹션 1 - 새 루틴 작성하기**
- 오늘 운동을 수행하면서 머신을 추가할 때마다 루틴에 자동으로 쌓임
- 운동 종료 후 "이 루틴을 저장할까요?" 옵션 제공
- 저장 시 루틴 이름 입력 후 저장
- 세트/중량은 루틴에 포함되지 않음, 머신 순서만 저장

**섹션 2 - 이전에 작성한 운동일지 참고하기**
- 같은 헬스장에서 같은 부위로 운동했던 과거 운동일지 표시
- 날짜, 사용한 머신 리스트, 세트 기록을 참고용으로만 표시
- 선택 시 머신 리스트만 오늘 세션에 가져옴
- 중량과 세트는 절대 자동 입력되지 않음

**섹션 3 - 헬스장 추천 루틴**
- 헬스장 운영자/트레이너가 등록한 추천 루틴
- 선택 시 머신 리스트만 오늘 세션에 가져옴
- 세트/중량 자동 입력 없음

**섹션 4 - 다른 유저 루틴**
- 같은 헬스장 다른 회원들이 공유한 루틴
- 선택 시 머신 리스트만 오늘 세션에 가져옴
- 세트/중량 자동 입력 없음

### 오늘의 운동 리스트 화면 (TodayWorkoutListScreen)
루틴 참고 후 생성되는 화면
- 머신 리스트만 표시
- 머신 추가/제거/순서 변경 가능
- 세트 기록은 각 머신 수행 후 직접 입력

### 데이터 구조

routine:
  id, name, user_id, gym_id, body_part, created_at

routine_machine:
  routine_id, machine_id, order

### 헬스장 커뮤니티
GymDetailModal에 Community 탭 추가
기존 탭: Machines | Reviews
변경 탭: Machines | Reviews | Community

Community 탭 내부:
- Announcements: 헬스장이 게시하는 공지사항 리스트 (최신순)
- Send Request: 사용자가 헬스장에 익명으로 요청 전송

gym_announcement:
  id, gym_id, title, content, created_at

gym_request:
  id, gym_id, message, created_at
  (user_id 없음 - 완전 익명, 다른 유저에게 비공개)
