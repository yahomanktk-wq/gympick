## STEP 1: app.json 폰트 등록 확인 및 추가

`app.json` 을 열어서 `"fonts"` 또는 `"assetBundlePatterns"` 항목을 확인한다.

아래 항목이 없으면 `expo.assetBundlePatterns` 에 추가한다:

```json
"assetBundlePatterns": [
  "**/*",
  "assets/fonts/*"
]
```

이미 `"**/*"` 가 있으면 추가 불필요.

---

## STEP 2: useFonts 훅 설정 확인

`src/screens/flow/PostWorkoutLogModal.tsx` 상단 imports 를 확인한다.

`expo-font` import 가 없으면 추가:
```tsx
import { useFonts } from 'expo-font';
```

---

## STEP 3: PostWorkoutLogModal 메인 컴포넌트에 useFonts 추가

`PostWorkoutLogModal` 메인 컴포넌트 함수 내부 상단 (useState 선언들 근처)에
아래 훅이 없으면 추가한다:

```tsx
const [fontsLoaded] = useFonts({
  'MatchaCih': require('../../../assets/fonts/Matcha_Cih.ttf'),
  'MatSaleh':  require('../../../assets/fonts/Mat_Saleh.ttf'),
});
```

이미 useFonts 가 있다면 두 폰트를 기존 객체에 추가한다.

## STEP 4: CenteredOverlay 컴포넌트 폰트 적용

`src/screens/flow/PostWorkoutLogModal.tsx` 에서
`CenteredOverlay` 함수를 찾아서 아래 코드로 완전히 교체한다.

```tsx
export function CenteredOverlay({ exercises, logs, nickname, timestamp, muscleLabel, tc, photoW, photoH }: OverlayProps) {
  const COL_COUNT = 2;
  const COL_W = Math.floor((photoW - OVERLAY_PAD * 2 - 12) / COL_COUNT);
  return (
    <>
      {/* 상단 좌: 닉네임 */}
      <View style={{ position: 'absolute', top: OVERLAY_PAD, left: OVERLAY_PAD }}>
        <Text style={{ fontSize: 13, fontWeight: '900', color: tc, letterSpacing: 0.3, fontFamily: 'MatSaleh' }}>
          {nickname}
        </Text>
      </View>
      {/* 상단 우: 날짜 */}
      <View style={{ position: 'absolute', top: OVERLAY_PAD, right: OVERLAY_PAD, alignItems: 'flex-end' }}>
        <Text style={{ fontSize: 10, fontWeight: '700', color: tc, opacity: 0.85, fontFamily: 'MatSaleh' }}>
          {timestamp}
        </Text>
      </View>
      {/* 중앙 타이틀 - Matcha_Cih 폰트 */}
      <View style={{ position: 'absolute', top: OVERLAY_PAD + 44, left: OVERLAY_PAD, right: OVERLAY_PAD, alignItems: 'center' }}>
        <Text style={{
          fontSize: 32,
          fontWeight: '900',
          color: tc,
          letterSpacing: -0.5,
          textDecorationLine: 'underline',
          textAlign: 'center',
          fontFamily: 'MatchaCih',
        }}>
          {muscleLabel}
        </Text>
      </View>
      {/* 2열 운동 목록 - Mat_Saleh 폰트 */}
      <View style={{
        position: 'absolute',
        top: OVERLAY_PAD + 44 + 52,
        left: OVERLAY_PAD,
        right: OVERLAY_PAD,
        flexDirection: 'row',
        flexWrap: 'wrap',
        gap: 8,
        alignContent: 'flex-start',
      }}>
        {exercises.slice(0, 8).map(ex => {
          const sets = logs[ex.id] ?? [];
          const setsLine = sets.map(st => `${st.weight} × ${st.reps}`).join(' / ');
          return (
            <View key={ex.id} style={{ width: COL_W, marginBottom: 10 }}>
              <Text style={{
                fontSize: 9,
                fontWeight: '900',
                color: tc,
                letterSpacing: 0.3,
                marginBottom: 2,
                fontFamily: 'MatSaleh',
              }} numberOfLines={1}>
                {`[${ex.brand.toUpperCase()}] ${ex.name.toUpperCase()}`}
              </Text>
              {setsLine ? (
                <Text style={{
                  fontSize: 8,
                  fontWeight: '600',
                  color: tc,
                  opacity: 0.85,
                  fontFamily: 'MatSaleh',
                }} numberOfLines={1}>
                  {setsLine}
                </Text>
              ) : null}
            </View>
          );
        })}
        {exercises.length > 8 && (
          <Text style={{ fontSize: 8, fontWeight: '700', color: tc, opacity: 0.6, fontFamily: 'MatSaleh' }}>
            {`+${exercises.length - 8} more...`}
          </Text>
        )}
      </View>
      {/* 하단 중앙 로고 */}
      <View style={{ position: 'absolute', bottom: OVERLAY_PAD, left: 0, right: 0, alignItems: 'center' }}>
        <GymPickLogo color={tc} width={Math.round(LOGO_STRIP_W * 0.85)} height={Math.round(LOGO_STRIP_H * 0.85)} />
      </View>
    </>
  );
}
```

## STEP 5: 폰트 로딩 전 fallback 처리 확인

`PostWorkoutLogModal` 메인 컴포넌트에서 `fontsLoaded` 가 false 일 때
오버레이가 렌더링되어도 앱이 크래시되지 않도록,
`fontsLoaded` 가 false 이면 시스템 폰트로 fallback 되는 게 React Native 기본 동작이므로
별도 처리 불필요. 확인만 한다.
