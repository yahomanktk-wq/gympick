# 목적 (읽기 전용 조사 — 코드 수정 절대 금지)

운동일지 작성 완료 시 생성되는 "오운완" 인증샷 이미지(`photoUri` / `compositeUri`)가
앱 내 어느 화면들에서, 각각 어떤 방식으로, 몇 장씩 노출되는지 전체적으로 조사한다.
아무것도 수정하지 않는다.

## 조사 항목

### 1. 오운완 사진의 원천 데이터 확인

- `WorkoutFeedPost`, `WorkoutLog` 타입 정의 위치와 `photoUri`/`compositeUri` 필드가
  각각 무엇을 의미하는지 (예: photoUri=원본 사진, compositeUri=오버레이 합성 사진 등
  주석이나 사용 맥락으로 유추)
- 오운완 사진이 실제로 어디서 생성/업로드되는지 (예: 운동 완료 후 카메라 촬영 →
  합성 → Supabase Storage 업로드 흐름이 있는 파일/함수 위치)
- `fetchActiveFeedPosts`, `fetchWorkoutLogs` 등 오운완/운동 기록 관련 데이터를
  가져오는 함수들이 정의된 파일 위치와 함수 시그니처, 특히 각 함수가 몇 개까지
  가져오는지(LIMIT, 페이지네이션 여부) 확인

### 2. 이 사진이 노출되는 모든 화면 조사

프로젝트 전체(`src/screens/`, `src/components/`)에서 `photoUri` 또는 `compositeUri`를
사용하는 모든 위치를 grep해서, 화면별로 정리한다. 최소한 아래 화면들은 반드시
확인하되, grep 결과 다른 화면에서도 쓰인다면 전부 포함한다:

a. **HomeScreen.tsx**
   - "이번 주 운동" 주간 썸네일 행 (weekThumbBox) — 몇 개(요일 수)까지 노출되는지,
     사진이 없는 날은 어떻게 표시되는지
   - "오늘의 오운완" 자동 스크롤 피드 (AutoScrollOunwan) — `fetchActiveFeedPosts()`
     호출 시 몇 개까지 가져오는지, 필터링(타겟부위 매칭) 로직도 함께 확인

b. **JournalScreen.tsx** (파일이 프로젝트에 있다면)
   - 주간/월간 운동일지에서 오운완 사진이 어떻게 노출되는지, 목록형인지 캘린더형인지
   - 한 화면에 최대 몇 개까지 보이는지 (스크롤 시 추가 로드되는 페이지네이션 여부 포함)

c. **WorkoutFeed 화면** (HomeScreen의 "더보기"가 이동하는 `nav.navigate('WorkoutFeed')`
   대상 화면 — 파일명을 찾아서 확인)
   - 전체 피드 형태로 오운완 사진들이 어떻게 노출되는지 (그리드/리스트, 무한스크롤
     여부, 한 번에 몇 개 로드하는지)

d. **GymDetailModal.tsx** (커뮤니티 탭)
   - 헬스장 상세의 커뮤니티 탭에서도 오운완 사진이 노출되는지 확인. 노출된다면
     해당 헬스장에서 작성된 오운완만 필터링하는지, 몇 개까지 보이는지

e. **PRHistoryScreen.tsx**, **FavoritesScreen.tsx**, **ProfileScreen.tsx** 등
   - 이 화면들에서도 오운완 사진이 노출되는지 grep으로 확인. 노출된다면 위와 동일한
     기준으로 조사

f. 그 외 grep 결과 발견되는 화면이 있다면 전부 포함

### 3. 각 화면별 노출 개수/제한 정리

각 화면마다 다음을 표로 정리:
- 화면 이름
- 노출 위치 설명 (섹션 이름)
- 데이터 소스 함수/쿼리
- 한 번에 가져오는 개수 제한 (LIMIT 값 또는 코드상 슬라이스 개수, 없으면 "제한 없음"
  으로 표기)
- 실제 화면에 렌더링되는 최대 개수 (스크롤 가능 여부 포함 — 무한 스크롤이면 "제한
  없음(무한 스크롤)"로 표기)
- 정렬 기준 (최신순, 타겟부위 매칭 우선 등)

### 4. 이미지 로딩 방식도 함께 확인

- 각 위치에서 오운완 이미지를 렌더링할 때 `expo-image`를 쓰는지 순정 `Image`를
  쓰는지, 그리고 이전에 조사된 `getMachineImageUrl` 같은 리사이즈 로직이 오운완
  사진에도 적용되고 있는지, 아니면 원본 그대로 로드되는지 (오운완 사진은
  machine-images 버킷이 아니라 별도 버킷/경로일 가능성이 높으므로 그 버킷 이름과
  구조도 함께 확인)

## 출력 형식

- 화면별 조사 내용 (파일 경로 + 줄 번호 + 코드 그대로)
- 3번 항목 표
- 마지막에 "오운완 사진이 앱 전체에서 노출되는 지점 요약" 리스트
