## 수정 3: 세트 추가/복사 시 배너 높이 측정 후 정확한 위치로 스크롤 (방법 B)

### 개요
SetProgressBanner 높이를 `onLayout`으로 측정해 ref에 저장하고,
세트 추가/복사 시 `scrollTo({ y: bannerHeight + offset })`으로
새 세트 입력 영역 시작 위치로 스크롤한다.

### SetLoggingStep 수정

#### imports 확인
SetLoggingStep은 이미 `useRef`를 사용 중이므로 추가 import 불필요.
`useRef` 두 개를 사용한다:
- `scrollRef`: 기존 ScrollView ref
- `bannerHeightRef`: 배너 높이 저장 (number, 초기값 0)

#### SetLoggingStep 함수 내부 수정

```tsx
function SetLoggingStep({ exercise, sets, note, onChange, onAdd, onCopyPrev, onRemove, onNoteChange, onSave, onFinish, onBack, onClose }: { ... }) {
  const scrollRef       = useRef<ScrollView>(null);
  const bannerHeightRef = useRef<number>(0);           // ← 추가
  const hasSets = sets.length > 0 && sets.some(s => s.weight > 0 || s.reps > 0);

  // 배너 아래 새 세트 위치로 스크롤하는 헬퍼
  function scrollToNewSet() {
    setTimeout(() => {
      // 배너 높이 + 힌트 텍스트/머신 헤더 영역(약 120px) + 여유(20px) 만큼 스크롤
      const targetY = bannerHeightRef.current + 140;
      scrollRef.current?.scrollTo({ y: targetY, animated: true });
    }, 100);
  }

  function handleAdd() {
    onAdd();
    scrollToNewSet();    // ← scrollToEnd 대신
  }

  function handleCopyPrev() {
    Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
    onCopyPrev();
    scrollToNewSet();    // ← scrollToEnd 대신
  }

  const completedSets = sets.slice(0, -1);

  return (
    <SafeAreaView style={s.safe}>
      <NavHeader title="세트 기록" onBack={onBack} onClose={onClose} />
      <StepBar total={5} current={2} />
      {completedSets.length > 0 && (
        <SetProgressBanner
          sets={completedSets}
          machineName={exercise.name}
          onLayout={(height) => { bannerHeightRef.current = height; }}   // ← 추가
        />
      )}
      <ScrollView ref={scrollRef} ...>
        ...
      </ScrollView>
      ...
    </SafeAreaView>
  );
}
```

### 스크롤 오프셋 설명
- `bannerHeightRef.current`: 배너 자체 높이 (세트 수에 따라 동적)
- `+ 140`: ScrollView 시작 후 새 세트 블록 상단까지의 고정 거리
  (listPad paddingTop ≈ 20 + 힌트텍스트 ≈ 30 + SetCard 헤더(머신명/부위) ≈ 60 + 내 PR row ≈ 30)
- 이 값은 실제 테스트 후 조정 가능 (너무 많이 스크롤되면 줄이고, 부족하면 늘린다)
- `marginHorizontal: 16` + `marginTop: 10` 등 배너 외부 여백은 배너 onLayout height에 포함되지 않으므로
  `+ 26` 추가 여유를 더해 총 `+ 140` 사용

## 검증 포인트
1. 배너 헤더에 "완료된 세트 · {머신명}" 표시, 머신명 길어도 잘림 처리됨
2. 각 세트 행이 이전보다 작게 표시됨 (폰트 20→15)
3. 세트 추가 탭 → 배너가 화면에 유지되고 새 세트 입력 영역이 배너 아래로 스크롤됨
4. 이전 세트 복사 탭 → 동일하게 동작
5. 세트 수가 늘어나면 배너 높이가 커지고, 스크롤 위치도 그에 맞게 자동 조정됨
6. 타입스크립트 에러 없음
