## 2단계 — expo-constants 설치 확인
package.json의 dependencies에 "expo-constants"가 이미 있는지 확인한다(위 1단계에서
이미 확인했다면 이 단계는 건너뛴다).
- 혹시라도 없다면: `npx expo install expo-constants` 실행. 이 명령으로 package.json과
  package-lock.json(또는 yarn.lock)이 추가로 바뀔 수 있는데, 바뀌었다면 이것도 3단계
  git add 대상에 포함시킬 것.

## 3단계 — 스테이징
아래 파일만 정확히 add한다. `git add -A`나 `git add .`는 절대 사용하지 말 것.

```
git add App.tsx app.json package.json package-lock.json src/screens/flow/PostWorkoutLogModal.tsx src/screens/admin/AdminDashboard.tsx src/screens/NotificationsScreen.tsx src/screens/MyRequestsModal.tsx src/data/freeWeightsGymVisual.ts src/lib/db/appUpdate.ts src/components/AppUpdateModal.tsx
```

## 4단계 — 커밋
레포 루트에 이미 준비되어 있는 커밋 메시지 파일을 사용한다 (직접 -m으로 타이핑하지 말 것):

```
git commit -F commit_message_task.txt
```

## 5단계 — 푸시
```
git push
```
