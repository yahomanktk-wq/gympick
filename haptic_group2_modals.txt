## 공통 규칙
1. 각 파일 상단에 `import * as Haptics from 'expo-haptics';` 가 없으면 추가
2. 이미 Haptics 호출이 있는 버튼은 스킵
3. disabled 상태 버튼에는 추가하지 않음
4. Switch 컴포넌트에는 추가하지 않음
5. ScrollView/FlatList 안의 대형 카드(머신카드 전체 탭) 는 스킵
6. 햅틱은 onPress 핸들러 첫 줄에 추가

## 강도 기준
- `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light)`
  → 일반 탭, 필터 칩, 탭 전환, 즐겨찾기 토글, 목록 아이템
- `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium)`
  → 저장, 확인, 루틴 선택 완료, 운동 시작 CTA, 즐겨찾기 추가/제거
- `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Heavy)`
  → 삭제, 리뷰 삭제, 경고성 액션

## 적용 방법 예시
```tsx
// 변경 전
<TouchableOpacity onPress={handleSave}>

// 변경 후
<TouchableOpacity onPress={() => {
  Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium);
  handleSave();
}}>

// 이미 인라인 함수인 경우
// 변경 전
<TouchableOpacity onPress={() => { doSomething(); }}>

// 변경 후
<TouchableOpacity onPress={() => {
  Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
  doSomething();
}}>
```

## 주의사항
- 기존 onPress 로직을 절대 변경하지 말 것 (햅틱 한 줄만 추가)
- 파일 내 다른 코드(스타일, 상태, 로직) 일절 건드리지 말 것
- 타입스크립트 에러 없을 것
