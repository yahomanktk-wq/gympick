## 변경 사항 2가지

---

## 1. '돌아가기' + '플래시' 버튼을 '화면을 탭하여 촬영' 텍스트와 같은 줄로 이동

현재 구조:
```
[화면을 탭하여 촬영]        ← 상단 단독 한 줄
[카메라 뷰파인더]
[돌아가기]   [플래시 OFF]   ← 하단 한 줄
```

변경 후 구조:
```
[돌아가기] [화면을 탭하여 촬영] [플래시 OFF]   ← 상단 한 줄
[카메라 뷰파인더]
```

### 1-1. 상단 hint 텍스트 단독 View 제거

기존:
```tsx
      <Text style={styles.hint}>
        {cameraReady ? '화면을 탭하여 촬영' : '카메라 준비 중...'}
      </Text>
```
이 블록을 삭제한다.

### 1-2. 하단 controls View를 카메라 뷰파인더 위로 이동하고 구조 변경

기존 하단 컨트롤 블록 전체:
```tsx
      {/* 하단 컨트롤: 돌아가기 + 플래시 */}
      <View style={styles.controls}>
        <TouchableOpacity
          style={styles.cancelRowBtn}
          onPress={onCancel}
          activeOpacity={0.8}
        >
          <Ionicons name="chevron-back" size={18} color={C.text} />
          <Text style={styles.cancelRowBtnText}>돌아가기</Text>
        </TouchableOpacity>

        <TouchableOpacity
          style={[styles.flashBtn, flash === 'on' && styles.flashBtnOn]}
          onPress={() => setFlash(f => f === 'off' ? 'on' : 'off')}
          activeOpacity={0.8}
        >
          <Ionicons
            name={flash === 'on' ? 'flash' : 'flash-off'}
            size={18}
            color={flash === 'on' ? C.bg : C.text}
          />
          <Text style={[styles.flashBtnText, flash === 'on' && { color: C.bg }]}>
            {flash === 'on' ? '플래시 ON' : '플래시 OFF'}
          </Text>
        </TouchableOpacity>
      </View>
```

이 블록을 삭제하고, 카메라 뷰파인더 TouchableOpacity 바로 위에 아래 블록을 삽입한다:

```tsx
      {/* 상단 컨트롤: 돌아가기 + 힌트 텍스트 + 플래시 */}
      <View style={styles.controls}>
        <TouchableOpacity
          style={styles.cancelRowBtn}
          onPress={onCancel}
          activeOpacity={0.8}
        >
          <Ionicons name="chevron-back" size={18} color={C.text} />
          <Text style={styles.cancelRowBtnText}>돌아가기</Text>
        </TouchableOpacity>

        <Text style={styles.hint}>
          {cameraReady ? '화면을 탭하여 촬영' : '카메라 준비 중...'}
        </Text>

        <TouchableOpacity
          style={[styles.flashBtn, flash === 'on' && styles.flashBtnOn]}
          onPress={() => setFlash(f => f === 'off' ? 'on' : 'off')}
          activeOpacity={0.8}
        >
          <Ionicons
            name={flash === 'on' ? 'flash' : 'flash-off'}
            size={18}
            color={flash === 'on' ? C.bg : C.text}
          />
          <Text style={[styles.flashBtnText, flash === 'on' && { color: C.bg }]}>
            {flash === 'on' ? '플래시 ON' : '플래시 OFF'}
          </Text>
        </TouchableOpacity>
      </View>
```

## 2. '화면을 탭하여 촬영' 텍스트 색상 변경

기존:
```tsx
  hint: {
    fontSize: 12,
    color: C.textDim,
    fontWeight: '600',
  },
```

변경 후:
```tsx
  hint: {
    fontSize: 12,
    color: C.text,
    fontWeight: '700',
  },
```

`C.textDim` (가장 흐린 색) → `C.text` (기본 텍스트 색, 가장 선명)
fontWeight도 '600' → '700' 으로 조금 더 굵게.

## 동작 확인 체크리스트

1. 카메라 활성화 시 상단에 [돌아가기] [화면을 탭하여 촬영] [플래시 OFF] 한 줄 표시 ✅
2. 하단에 버튼 없음 (카메라 뷰파인더 바로 아래 여백만) ✅
3. '화면을 탭하여 촬영' 텍스트가 기존보다 선명하게 보임 ✅
4. 카메라 준비 중일 때 '카메라 준비 중...' 텍스트 동일 위치에 표시 ✅
5. 플래시 ON/OFF 토글 정상 동작 ✅
6. 돌아가기 탭 → 카메라 닫힘 ✅
