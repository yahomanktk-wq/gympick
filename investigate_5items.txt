[조사 5] 같은 머신을 운동 중 두 번 (처음 + 마무리) 기록 가능한지
================================================================================
질문: A머신을 처음에 하고, 다른 운동들 한 뒤, 마무리로 A머신을 한 번 더.
      현재 기능으로 같은 머신을 두 번 기록할 수 있나? 안 되면 왜?

조사할 것:
  파일: src/screens/flow/PostWorkoutLogModal.tsx
- 머신 선택 상태가 어떻게 저장되는지: Set인지 배열인지
  ("selectedExercises|selectedMachines|exercises|Set<|machineId" 검색)
  → Set이면 중복 불가, 배열이면 가능성 있음
- 같은 머신을 다시 선택하려 할 때 막는 로직이 있는지 (이미 선택됨 처리, disabled 등)
- 운동 기록(세션) 데이터 구조에서 같은 머신 중복 항목을 허용하는지:
  src/data/types.ts 의 WorkoutSession / WorkoutEntry 구조
  src/lib/db/workouts.ts 의 insert 로직 (entry가 machineId로 유니크한지)
- 세트 입력 후 '다음 머신'으로 갈 때, 같은 머신 재추가 경로가 있는지

[결과에 적을 것]
- 머신 선택 자료구조 (Set/배열) + 중복 허용 여부
- 같은 머신 두 번 기록이 현재 가능한지 (가능/불가능/부분가능)
- 불가능하면 막는 지점(줄 번호)과, 가능하게 하려면 어디를 봐야 하는지
- 세션 저장 구조가 중복 머신을 담을 수 있는지
