[매니저 온보딩 개선] 문구 다듬기 + 폰트 확대 + 완료 시 프로필 이동
================================================================================

■ 작업 개요
매니저 첫 로그인 온보딩(슬라이드 5개)을 개선한다.
  (1) 전체 슬라이드 문구를 간결하게 다듬고 줄바꿈(\n) 추가
  (2) 슬라이드 2: '머신으로 찾아요' 본문을 '직접 관리 + 헬스장 직접 관리 뱃지' 안내로 교체
  (3) 폰트 확대: title 22→25, body 15→17 (lineHeight 24→28)
  (4) 마지막 "시작하기" → 온보딩 완료 처리 + 프로필 탭으로 이동

■ 변경 파일 (3개)
  1. src/data/managerManual.ts                      ← 슬라이드 문구
  2. src/screens/manager/ManagerOnboardingModal.tsx ← 폰트 + 완료 시 프로필 이동(콜백)
  3. src/screens/HomeScreen.tsx                     ← 모달 onComplete에서 프로필 이동 연결

⚠ 파일은 Windows(CRLF)에서 작성됐을 수 있음. str_replace 매칭 실패 시
  해당 파일을 Read로 먼저 확인하고, 깨진 한글/공백을 실제 파일 기준으로 맞출 것.

[파일 3] src/screens/HomeScreen.tsx — onFinish로 프로필 이동 연결
================================================================================
ManagerOnboardingModal 렌더(581~587번 근처)에 onFinish prop을 추가해
온보딩 끝까지 본 뒤 프로필 탭으로 이동시킨다.

※ 먼저 해당 렌더부를 확인한다. 보통 아래 형태:
    <ManagerOnboardingModal
      visible={showManagerOnboarding}
      onComplete={markManagerOnboarded}
    />
  (onComplete에 넘기는 함수명/형태는 실제 코드에 맞춰 유지)

위 요소에 onFinish 콜백을 아래처럼 추가한다.
(HomeScreen에는 이미 네비게이션 객체가 있음: 이 파일은 nav.navigate(...)를
 여러 곳에서 사용 중 — 동일한 nav 변수를 사용한다.)

예시(실제 onComplete 줄은 보존하고 onFinish만 추가):
    <ManagerOnboardingModal
      visible={showManagerOnboarding}
      onComplete={markManagerOnboarded}
      onFinish={() => nav.navigate('Profile')}
    />

  ※ 만약 이 파일의 네비게이션 변수명이 nav가 아니라 navigation이면 그 이름을 사용.
    (HomeScreen 상단에서 useNavigation() 결과를 받는 변수명을 그대로 사용)
  ※ 프로필 탭의 라우트명이 'Profile'이 맞는지 확인. 다른 이름이면(예: 'ProfileTab')
    그 이름으로 navigate. (TabNavigator의 프로필 탭 name 기준)

■ 완료 후 자체 점검
================================================================================
1) npx tsc --noEmit → 신규 에러 0건
2) managerManual.ts: 슬라이드 2 body가 '직접 머신을 등록하고...' + '헬스장 직접 관리' 안내로 바뀌었는지
   ('헬스장 직접 관리' 작은따옴표가 \' 로 이스케이프되어 문자열이 안 깨지는지 확인)
3) 모달 title 25 / body 17 / lineHeight 28 적용됐는지
4) HomeScreen 모달에 onFinish 추가됐는지 (onComplete는 보존)

■ 사람이 직접 할 일 (디바이스 테스트)
- 매니저 신규 계정(또는 profiles.manager_onboarded=false로 리셋) 로그인 → 홈에서 온보딩 모달
- 각 슬라이드 줄바꿈/글자 크기 가독성 확인 (특히 슬라이드 2/3이 한 화면에 잘 들어오는지)
- '건너뛰기' → 이동 없이 닫힘
- 끝까지 넘겨 '시작하기' → 모달 닫히고 프로필 탭으로 이동되는지
- (재확인) 온보딩 다시 안 뜨는지(manager_onboarded=true 저장)

※ 온보딩 다시 보려면 Supabase에서:
  update profiles set manager_onboarded = false where id = '<매니저 user id>';
