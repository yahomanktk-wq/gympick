FEATURE OVERVIEW
Machine Olympic is a tournament-style feature where machines of the same body part compete against each other based on user votes. It collects user preference data and generates machine popularity rankings.

STEP 1 - Create src/data/olympicStore.ts

Create a data store with the following:

Types:
  OlympicVote {
    id: string
    machineId: string
    opponentId: string
    bodyPart: string
    round: string
    gymId: string or null
    createdAt: string
  }

  OlympicRank {
    machineId: string
    bodyPart: string
    winCount: number
    loseCount: number
    winRate: number
  }

Functions:
  saveVote(vote: OlympicVote): void
  getVotes(): OlympicVote[]
  getRankings(bodyPart: string): OlympicRank[]
  getMachineRecord(machineId: string): { wins: number, losses: number, winRate: number }
  clearVotes(): void
