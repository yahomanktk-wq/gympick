TASK 2: Remove background location permission
==================================================

PROBLEM:
Background location permission causes App Store and Play Store rejection.
GymPick only needs location while the app is in use (foreground only).

Step 1: Open app.json
  Find any location-related permissions.
  Remove or ensure these are NOT present:
    iOS: "NSLocationAlwaysAndWhenInUseUsageDescription"
    iOS: "NSLocationAlwaysUsageDescription"
    Android: "ACCESS_BACKGROUND_LOCATION"

  Keep ONLY the foreground location permission:
    iOS: "NSLocationWhenInUseUsageDescription"
    Android: "ACCESS_FINE_LOCATION" or "ACCESS_COARSE_LOCATION"

Step 2: Check if there is an app.config.js or expo config file.
  If so, apply the same changes there too.

Step 3: Search the entire codebase for any usage of:
  - "always" location permission requests
  - BackgroundFetch related to location
  - Location.requestBackgroundPermissionsAsync()
  - Location.startLocationUpdatesAsync()
  - TaskManager (if used for background location)

  If found, remove or replace with foreground-only alternatives:
    Location.requestForegroundPermissionsAsync() — use this instead
    Location.getCurrentPositionAsync() — use this for one-time location fetch

Step 4: In app.json, add proper location permission descriptions:
  "infoPlist": {
    "NSLocationWhenInUseUsageDescription": "주변 헬스장을 찾기 위해 위치 정보가 필요합니다.",
    "ITSAppUsesNonExemptEncryption": false
  }

  For Android in app.json:
  "permissions": ["ACCESS_FINE_LOCATION", "ACCESS_COARSE_LOCATION"]
  (Do NOT include ACCESS_BACKGROUND_LOCATION)

TASK 4: Add permission request purpose strings
==================================================

Permission request dialogs must clearly explain WHY the app needs each permission.
Vague descriptions cause rejection.

Step 1: Update app.json iOS infoPlist with clear Korean descriptions:

  "infoPlist": {
    "NSLocationWhenInUseUsageDescription": "주변 헬스장을 찾기 위해 현재 위치가 필요합니다. 위치 정보는 헬스장 검색 목적으로만 사용됩니다.",
    "NSCameraUsageDescription": "머신을 스캔하여 자동으로 인식하기 위해 카메라 접근이 필요합니다.",
    "NSPhotoLibraryUsageDescription": "운동 완료 사진을 저장하거나 프로필 사진을 설정하기 위해 사진 라이브러리 접근이 필요합니다.",
    "NSPhotoLibraryAddUsageDescription": "운동 완료 카드 이미지를 사진 앱에 저장하기 위해 접근이 필요합니다.",
    "ITSAppUsesNonExemptEncryption": false
  }

Step 2: Update app.json Android permissions section:
  Check current permissions array in android section.
  Add permission descriptions if the framework supports it.
  Make sure only necessary permissions are listed:
    "ACCESS_FINE_LOCATION" — for nearby gym search
    "CAMERA" — for machine scan feature
    "READ_EXTERNAL_STORAGE" / "WRITE_EXTERNAL_STORAGE" — only if needed for photo save
    "READ_MEDIA_IMAGES" — Android 13+ replacement for storage permission

  Remove any permissions that are not actually used by the app.

Step 3: Search the codebase for permission requests using Expo APIs:
  Camera.requestCameraPermissionsAsync()
  MediaLibrary.requestPermissionsAsync()
  Location.requestForegroundPermissionsAsync()

  For each permission request, make sure there is a user-facing explanation
  shown BEFORE the system dialog appears (pre-permission rationale screen or Alert).

  Example for camera:
    Show Alert before requesting:
      Alert.alert(
        '카메라 권한 필요',
        '머신을 자동으로 인식하기 위해 카메라 접근 권한이 필요합니다.',
        [
          { text: '취소', style: 'cancel' },
          { text: '허용', onPress: () => Camera.requestCameraPermissionsAsync() }
        ]
      )
