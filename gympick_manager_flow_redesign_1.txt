[배경 — 설계 변경]
기존 흐름:
ManagerRequestModal(매니저 신청 + 간략한 헬스장 정보 입력) → 관리자 승인 시
AdminDashboard.handleApproveApplication에서 gyms 테이블에 헬스장 자동 생성
→ 문제: geocoding 미동작, 좌표 누락, 거리 미표시 버그가 계속 발생

변경할 흐름:
ManagerRequestModal은 매니저 신청용 간략한 정보만 받는 것으로 역할을 한정.
관리자가 승인하면 매니저 권한만 부여하고, 헬스장 데이터는 생성하지 않음.
승인받은 매니저는 ManagerDashboard에서 헬스장 등록 신청을 직접 진행.
ManagerDashboard의 헬스장 등록 경로는 이미 geocoding + 좌표 저장이 정상 동작함 (확인됨).


[1] AdminDashboard.tsx — handleApproveApplication에서 gyms INSERT 제거 (실제로 코드 수정)

1. handleApproveApplication 함수 전체를 읽어서 보여줘.

2. 이 함수 안에서 gyms 테이블에 INSERT하는 코드 블록을 찾아서 제거해줘.
   - geocodeAddress 호출, gymId 생성, supabase.from('gyms').insert(...) 등
     헬스장 생성과 직접 관련된 코드를 제거.
   - 단, manager_requests 상태 업데이트(status → approved)나 유저 역할 변경 같은
     매니저 권한 부여 관련 코드는 반드시 그대로 유지해줘.
   - 제거 후 함수가 정상적으로 컴파일되고 매니저 권한 부여만 깔끔하게 처리되는지
     확인해줘.

3. 수정 전/후를 빠짐없이 보여줘.


[2] ManagerDashboard.tsx — 이미 관리 중인 헬스장이 있으면 추가 등록 신청 차단
(실제로 코드 수정)

1. ManagerDashboard에서 매니저가 새 헬스장 등록을 신청하는 진입점(버튼 또는 모달 오픈)을
   찾아줘.

2. 화면 진입 시 또는 관련 데이터 로드 시점에, 현재 매니저(userId 기준)가 이미
   gyms 테이블에서 manager_id로 연결된 헬스장을 갖고 있는지 Supabase로 확인해줘.

3. 이미 관리 중인 헬스장이 있으면:
   - 헬스장 등록 신청 버튼을 비활성화(disabled)하거나
   - 탭 시 Alert("이미 헬스장을 관리 중이에요. 매니저는 하나의 헬스장만 관리할 수
     있어요.")를 띄우고 return
   둘 중 UI에 더 자연스러운 방식으로 구현해줘 (어느 쪽 선택했는지 이유 알려줘).

4. 수정 전/후를 빠짐없이 보여줘.


[3] (선택 확인) ManagerRequestModal — 헬스장 정보 입력 필드 처리

현재 ManagerRequestModal에 헬스장 이름, 위치 등 헬스장 정보를 입력하는 필드가 있을 수
있음. 이 필드들이 이제 "참고용 정보"로만 쓰이고 실제 헬스장 생성에는 쓰이지 않으므로:
- 해당 필드들이 현재 어떤 용도로 manager_requests 테이블에 저장되는지 확인해줘.
- 만약 저장은 되지만 표시/안내 문구가 "이 정보로 헬스장이 등록됩니다" 같은 오해를
  살 만한 문구라면, "매니저 신청을 위한 참고 정보입니다. 승인 후 매니저 대시보드에서
  헬스장을 직접 등록할 수 있어요." 같은 안내 문구로 바꿔줘.
- 필드 자체를 제거하거나 입력 구조를 바꾸지는 마 — 관리자가 신청 내용을 검토할 때
  참고 정보로 여전히 유용함.

수정이 필요하면 수정 전/후 보여줘. 수정 불필요하면 현재 상태 그대로라고 알려줘.


[4] 헬스장 유형 표시 — 기존 방패 아이콘 제거 + 매니저 직접 관리 배지 추가
(실제로 코드 수정)

먼저 FindGymScreen.tsx의 헬스장 리스트 카드에서 기존에 표시되고 있는 방패 모양 아이콘을
찾아줘. 정확히 어떤 조건으로 표시되는지(예: 승인된 헬스장 전체에 표시, 특정 필드 기준 등)
코드를 읽고 알려줘.

그런 다음:

1. 기존 방패 아이콘과 그 조건 로직을 헬스장 리스트 카드에서 제거해줘.

2. 아래 새로운 표시 방식을 추가해줘.
gyms 테이블의 manager_id 유무로 헬스장 등록 유형을 구분한다:
- manager_id 있음 → 매니저(실제 운영자)가 직접 등록한 헬스장
- manager_id 없음 → 앱 운영자(짐픽)가 등록한 헬스장

표시 방식: 매니저 직접 관리 헬스장에만 방패 체크 아이콘 + 텍스트 표시.
앱 운영자 등록 헬스장은 별도 표시 없음.

아이콘: Ionicons의 "shield-checkmark" (또는 "shield-checkmark-outline")
색상: 파란색 계열 (#4A90E2 또는 비슷한 값)
텍스트: "헬스장 직접 관리" (fontSize 11, 같은 파란색 계열)

표시 위치 2곳:

1. FindGymScreen의 헬스장 리스트 카드 — 기존 방패 아이콘이 있던 자리 또는 자연스럽게
   어울리는 위치에 배치.

2. GymDetailModal의 헬스장 정보 탭 — 헬스장 이름 또는 주소 근처에 표시.

데이터: gym.manager_id 유무만 체크하면 돼. 별도 API 호출 불필요.

수정 전/후를 2곳 모두 빠짐없이 보여줘.
