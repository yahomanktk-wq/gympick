## 추가할 햅틱 3곳

---

### 1. 이전 세트 복사 버튼

`SetLoggingStep` 컴포넌트 내부의 `handleCopyPrev` 함수를 찾는다.

기존:
```tsx
  function handleCopyPrev() {
    onCopyPrev();
    setTimeout(() => {
      scrollRef.current?.scrollToEnd({ animated: true });
    }, 100);
  }
```

변경 후:
```tsx
  function handleCopyPrev() {
    Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
    onCopyPrev();
    setTimeout(() => {
      scrollRef.current?.scrollToEnd({ animated: true });
    }, 100);
  }
```

---

### 2. 저장하고 다음 머신 버튼

`SetLoggingStep` 컴포넌트의 CTA 버튼을 찾는다.

기존:
```tsx
        <TouchableOpacity
          style={[s.ctaBtn, !hasSets && s.ctaDisabled]}
          activeOpacity={0.85}
          onPress={onSave}
          disabled={!hasSets}
        >
          <Ionicons name="checkmark" size={18} color={C.bg} />
          <Text style={s.ctaTxt}>저장하고 다음 머신</Text>
        </TouchableOpacity>
```

변경 후:
```tsx
        <TouchableOpacity
          style={[s.ctaBtn, !hasSets && s.ctaDisabled]}
          activeOpacity={0.85}
          onPress={() => {
            Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success);
            onSave();
          }}
          disabled={!hasSets}
        >
          <Ionicons name="checkmark" size={18} color={C.bg} />
          <Text style={s.ctaTxt}>저장하고 다음 머신</Text>
        </TouchableOpacity>
```

---

### 3. XP 게이지 상승 / 레벨업

`handleSaveExercise` 함수 내부에서 XP 계산 후 팝업을 띄우는 블록을 찾는다.

기존:
```tsx
          setXpPopupData({ machineName, xpResult, levelData: updatedData, leveledUp, newLevel });
          setXpPopupVisible(true);
```

변경 후:
```tsx
          setXpPopupData({ machineName, xpResult, levelData: updatedData, leveledUp, newLevel });
          setXpPopupVisible(true);
          if (leveledUp) {
            Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success);
          } else {
            Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium);
          }
```

레벨업 시에는 Success 알림 햅틱, 일반 XP 획득 시에는 Medium 임팩트 햅틱으로 구분한다.

---

## 동작 확인 체크리스트

1. 세트 기록 화면에서 '이전 세트 복사' 탭 → 가벼운 햅틱 (Light) ✅
2. '저장하고 다음 머신' 탭 → 성공 알림 햅틱 (Success) ✅
3. 머신 저장 후 XP 획득 시 → Medium 임팩트 햅틱 ✅
4. 머신 저장 후 레벨업 시 → Success 알림 햅틱 ✅
