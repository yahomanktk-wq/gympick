## 버그 원인 분석

### 버그 1: 검정 화면 + 레이아웃 겹침
react-native-view-shot의 captureRef는 네이티브 카메라 피드(OpenGL/Metal 레이어)를
직접 캡처할 수 없다. 카메라 위에 view-shot을 씌워도 카메라 피드는 검정으로 나온다.

올바른 방식:
1. CameraView의 ref로 takePictureAsync() 호출 → 실제 사진 URI 획득
2. 그 URI를 부모로 전달 (photoUri로 저장)
3. 기존 overlayRef (사진 + 오버레이 합성 View) 는 그대로 유지

즉 WorkoutCameraOverlay는 "카메라 미리보기 + 오버레이 실시간 표시 + 셔터" 역할만 하고,
실제 합성(captureRef)은 기존 overlayRef에서 처리하는 구조로 변경한다.

### 버그 2: 다시 찍기 후 카메라 무반응
PostWorkoutLogModal의 카메라 렌더 조건이 `{!photoTaken && showCamera && (...)}` 이다.
다시 찍기 시 photoTaken = true 상태에서 showCamera = true로 바꿔도
!photoTaken 조건에 막혀 카메라가 렌더되지 않는다.

## 1단계: WorkoutCameraOverlay.tsx 전체 교체

아래 내용으로 파일 전체를 교체한다.

핵심 변경:
- captureRef 제거 → CameraView ref로 takePictureAsync() 사용
- 카메라가 준비될 때까지 촬영 버튼 비활성화 (cameraReady 상태)
- 촬영 완료 시 사진 URI만 부모로 전달 (합성은 부모의 overlayRef에서 처리)

```tsx
import React, { useRef, useState, useCallback } from 'react';
import {
  View,
  Text,
  TouchableOpacity,
  StyleSheet,
  Dimensions,
  ActivityIndicator,
} from 'react-native';
import { CameraView, useCameraPermissions, type CameraView as CameraViewType } from 'expo-camera';
import { Ionicons } from '@expo/vector-icons';
import { C, R } from '../../theme';
import GymPickLogo from '../../components/GymPickLogo';

const { width: SCREEN_W } = Dimensions.get('window');
const PHOTO_W = SCREEN_W - 32;
const PHOTO_H = Math.round(PHOTO_W * (4 / 3));

const LOGO_STRIP_H  = 14;
const LOGO_STRIP_W  = Math.round(LOGO_STRIP_H * (2805 / 279));
const OVERLAY_PAD   = 20;
const LOGO_EDGE_GAP = 8;

interface Props {
  gym: { name: string };
  exercises: { id: string; name: string; brand: string; targetMuscle: string }[];
  logs: Record<string, { weight: number; reps: number }[]>;
  nickname?: string;
  textColor: string;
  onCaptureDone: (uri: string) => void;
  onCancel: () => void;
}

export default function WorkoutCameraOverlay({
  gym,
  exercises,
  logs,
  nickname,
  textColor,
  onCaptureDone,
  onCancel,
}: Props) {
  const [permission, requestPermission] = useCameraPermissions();
  const [flash,        setFlash]        = useState<'off' | 'on'>('off');
  const [capturing,    setCapturing]    = useState(false);
  const [cameraReady,  setCameraReady]  = useState(false);
  const cameraRef = useRef<CameraViewType>(null);

  // 날짜/시간
  const now = new Date();
  const pad = (n: number) => String(n).padStart(2, '0');
  const ENG_DAYS = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'];
  const dateLabel   = `${now.getFullYear()}-${pad(now.getMonth() + 1)}-${pad(now.getDate())}(${ENG_DAYS[now.getDay()]})`;
  const timestamp   = `${dateLabel}_${pad(now.getHours())}:${pad(now.getMinutes())}`;
  const displayName = nickname ?? 'gympick_user';

  // 근육 라벨
  const muscleCounts = exercises.reduce<Record<string, number>>((acc, ex) => {
    acc[ex.targetMuscle] = (acc[ex.targetMuscle] ?? 0) + 1;
    return acc;
  }, {});
  const sortedMuscles = Object.entries(muscleCounts)
    .sort(([, a], [, b]) => b - a)
    .map(([m]) => m);
  const muscleLabel = sortedMuscles.length > 1
    ? sortedMuscles.slice(0, 2).join(' + ')
    : `${sortedMuscles[0] ?? 'WORKOUT'} Day`;

  // 로고 위치 계산
  const logoTlLeft = Math.round(LOGO_EDGE_GAP + LOGO_STRIP_H / 2 - LOGO_STRIP_W / 2);
  const logoTlTop  = Math.round(OVERLAY_PAD   + LOGO_STRIP_W / 2 - LOGO_STRIP_H / 2);
  const logoBrLeft = Math.round((PHOTO_W - LOGO_EDGE_GAP - LOGO_STRIP_H) + LOGO_STRIP_H / 2 - LOGO_STRIP_W / 2);
  const logoBrTop  = Math.round((PHOTO_H - OVERLAY_PAD - LOGO_STRIP_W)   + LOGO_STRIP_W / 2 - LOGO_STRIP_H / 2);

  const tc = textColor;

  // 탭 촬영: takePictureAsync로 실제 사진 URI 획득
  const handleTap = useCallback(async () => {
    if (capturing || !cameraReady || !cameraRef.current) return;
    setCapturing(true);
    try {
      const photo = await cameraRef.current.takePictureAsync({
        quality: 0.9,
        skipProcessing: false,
      });
      if (photo?.uri) {
        onCaptureDone(photo.uri);
      } else {
        setCapturing(false);
      }
    } catch (e) {
      console.error('[WorkoutCameraOverlay] 촬영 오류:', e);
      setCapturing(false);
    }
  }, [capturing, cameraReady, onCaptureDone]);

  // 권한 로딩 중
  if (!permission) {
    return (
      <View style={styles.container}>
        <ActivityIndicator color={C.accent} />
      </View>
    );
  }

  // 권한 미허용
  if (!permission.granted) {
    return (
      <View style={styles.container}>
        <Ionicons name="camera-outline" size={48} color={C.textDim} />
        <Text style={styles.permText}>카메라 권한이 필요합니다</Text>
        <TouchableOpacity style={styles.permBtn} onPress={requestPermission} activeOpacity={0.85}>
          <Text style={styles.permBtnText}>권한 허용</Text>
        </TouchableOpacity>
        <TouchableOpacity style={styles.cancelBtn} onPress={onCancel} activeOpacity={0.8}>
          <Text style={styles.cancelBtnText}>취소</Text>
        </TouchableOpacity>
      </View>
    );
  }

  return (
    <View style={styles.container}>
      <Text style={styles.hint}>
        {cameraReady ? '화면을 탭하여 촬영' : '카메라 준비 중...'}
      </Text>

      {/* 카메라 뷰파인더 + 오버레이 미리보기 */}
      <TouchableOpacity
        activeOpacity={1}
        onPress={handleTap}
        style={[styles.cameraWrap, { height: PHOTO_H }]}
        disabled={capturing || !cameraReady}
      >
        {/* 실제 카메라 피드 */}
        <CameraView
          ref={cameraRef}
          style={StyleSheet.absoluteFill}
          facing="back"
          flash={flash}
          onCameraReady={() => setCameraReady(true)}
        />

        {/* 오버레이: 실시간 미리보기용 (캡처 대상 아님) */}
        <View style={StyleSheet.absoluteFill} pointerEvents="none">

          {/* 좌상단 로고 90° */}
          <View style={[styles.logoAbsolute, { left: logoTlLeft, top: logoTlTop, transform: [{ rotate: '90deg' }] }]}>
            <GymPickLogo color={tc} width={LOGO_STRIP_W} height={LOGO_STRIP_H} />
          </View>

          {/* 우하단 로고 270° */}
          <View style={[styles.logoAbsolute, { left: logoBrLeft, top: logoBrTop, transform: [{ rotate: '270deg' }] }]}>
            <GymPickLogo color={tc} width={LOGO_STRIP_W} height={LOGO_STRIP_H} />
          </View>

          {/* 우상단: 닉네임 + 타임스탬프 */}
          <View style={styles.topRight}>
            <Text style={[styles.username,  { color: tc }]}>{displayName}</Text>
            <Text style={[styles.timestamp, { color: tc }]}>{timestamp}</Text>
          </View>

          {/* 좌하단: 근육 라벨 + 운동 목록 */}
          <View style={styles.bottomLeft}>
            <Text style={[styles.muscleTitle, { color: tc }]}>{muscleLabel}</Text>
            {exercises.slice(0, 7).map(ex => {
              const sets     = logs[ex.id] ?? [];
              const setsLine = sets.map(st => `${st.weight} x ${st.reps}`).join(' / ');
              return (
                <View key={ex.id} style={styles.exBlock}>
                  <Text style={[styles.exName, { color: tc }]} numberOfLines={1}>
                    {`[${ex.brand.toUpperCase()}] ${ex.name.toUpperCase()}`}
                  </Text>
                  {setsLine ? (
                    <Text style={[styles.exSet, { color: tc }]} numberOfLines={2}>
                      {setsLine}
                    </Text>
                  ) : null}
                </View>
              );
            })}
            {exercises.length > 7 && (
              <Text style={[styles.exName, { color: tc, opacity: 0.6, marginTop: 2 }]}>
                {`+${exercises.length - 7} more...`}
              </Text>
            )}
          </View>

          {/* 테두리 */}
          <View style={[styles.border, { borderColor: tc }]} />

          {/* 카메라 준비 중 딤 */}
          {!cameraReady && (
            <View style={styles.loadingDim}>
              <ActivityIndicator color={C.accent} size="large" />
            </View>
          )}

          {/* 촬영 중 딤 */}
          {capturing && (
            <View style={styles.capturingDim}>
              <ActivityIndicator color={C.accent} size="large" />
            </View>
          )}
        </View>
      </TouchableOpacity>

      {/* 하단 컨트롤: 돌아가기 + 플래시 */}
      <View style={styles.controls}>
        <TouchableOpacity
          style={styles.cancelRowBtn}
          onPress={onCancel}
          activeOpacity={0.8}
        >
          <Ionicons name="chevron-back" size={18} color={C.text} />
          <Text style={styles.cancelRowBtnText}>돌아가기</Text>
        </TouchableOpacity>

        <TouchableOpacity
          style={[styles.flashBtn, flash === 'on' && styles.flashBtnOn]}
          onPress={() => setFlash(f => f === 'off' ? 'on' : 'off')}
          activeOpacity={0.8}
        >
          <Ionicons
            name={flash === 'on' ? 'flash' : 'flash-off'}
            size={18}
            color={flash === 'on' ? C.bg : C.text}
          />
          <Text style={[styles.flashBtnText, flash === 'on' && { color: C.bg }]}>
            {flash === 'on' ? '플래시 ON' : '플래시 OFF'}
          </Text>
        </TouchableOpacity>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
```

### 2-3. onCameraCapture 콜백에서 setPhotoTaken 전에 setShowCamera(false) 확인

## 3단계: 동작 확인 체크리스트

1. 점선 카드 탭 → Alert (카메라로 찍기 / 사진 선택) ✅
2. 카메라로 찍기 탭 → 카메라 피드 실제로 보임 (검정 아님) ✅
3. "카메라 준비 중..." 텍스트 후 "화면을 탭하여 촬영"으로 변경 ✅
4. 카메라 영역 탭 → 실제 사진 촬영 → 오버레이 미리보기로 전환 ✅
5. 오버레이 미리보기에서 컬러칩 표시됨 ✅
6. 다시 찍기 탭 → Alert → 카메라로 찍기 탭 → 카메라 다시 정상 열림 ✅
7. 사진 선택 → 갤러리에서 선택 → 오버레이 미리보기 정상 ✅
8. 플래시 ON/OFF 정상 동작 ✅

## 주의사항

- WorkoutCameraOverlay는 이제 captureRef를 사용하지 않는다
- 실제 오버레이 합성(captureRef)은 기존 overlayRef (PostWorkoutLogModal의 photoTaken 블록) 에서만 처리
- WorkoutCameraOverlay의 오버레이는 "미리보기 전용" 이다
- 촬영된 사진(photoUri)이 overlayRef의 배경으로 들어가고, 그 위에 오버레이가 합성되어 저장됨
- takePictureAsync의 skipProcessing은 false로 유지 (iOS에서 올바른 방향 처리를 위해)
