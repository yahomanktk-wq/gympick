## 목표
PostWorkoutLogModal의 오운완 사진 단계에서
"카메라로 찍기" 선택 시 앱 외부 카메라가 아닌
앱 내 카메라 뷰파인더가 열리고,
오버레이 요소들이 실시간으로 카메라 피드 위에 표시되며,
카메라 영역을 탭하면 촬영되는 기능을 구현한다.


## 2단계: 신규 파일 생성

### 파일 경로
`src/screens/flow/WorkoutCameraOverlay.tsx`

### 역할
- expo-camera의 CameraView를 사용한 인앱 카메라
- 카메라 피드 위에 오운완 오버레이 요소 실시간 표시
- 화면 탭 → 촬영 (셔터 버튼 없음)
- 플래시 on/off 토글 버튼 (우상단)
- 촬영 완료 시 photoUri를 부모로 전달

### 전체 코드

```tsx
import React, { useRef, useState, useCallback } from 'react';
import {
  View,
  Text,
  TouchableOpacity,
  StyleSheet,
  Dimensions,
  ActivityIndicator,
} from 'react-native';
import { CameraView, useCameraPermissions, CameraType } from 'expo-camera';
import { captureRef } from 'react-native-view-shot';
import { Ionicons } from '@expo/vector-icons';
import { C, R } from '../../theme';
import GymPickLogo from '../../components/GymPickLogo';

const { width: SCREEN_W } = Dimensions.get('window');
const PHOTO_W = SCREEN_W - 32;
const PHOTO_H = Math.round(PHOTO_W * (4 / 3));

// Logo strip sizing (기존 PostWorkoutLogModal과 동일)
const LOGO_STRIP_H = 14;
const LOGO_STRIP_W = Math.round(LOGO_STRIP_H * (2805 / 279));
const OVERLAY_PAD  = 20;
const LOGO_EDGE_GAP = 8;

interface Props {
  gym: { name: string };
  exercises: { id: string; name: string; brand: string; targetMuscle: string }[];
  logs: Record<string, { weight: number; reps: number }[]>;
  nickname?: string;
  textColor: string;
  onCaptureDone: (uri: string) => void;
  onCancel: () => void;
}

export default function WorkoutCameraOverlay({
  gym,
  exercises,
  logs,
  nickname,
  textColor,
  onCaptureDone,
  onCancel,
}: Props) {
  const [permission, requestPermission] = useCameraPermissions();
  const [flash, setFlash]               = useState<'off' | 'on'>('off');
  const [capturing, setCapturing]       = useState(false);
  const captureAreaRef = useRef<View>(null);

  // 날짜/시간
  const now = new Date();
  const pad = (n: number) => String(n).padStart(2, '0');
  const ENG_DAYS = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'];
  const dateLabel = `${now.getFullYear()}-${pad(now.getMonth() + 1)}-${pad(now.getDate())}(${ENG_DAYS[now.getDay()]})`;
  const timestamp  = `${dateLabel}_${pad(now.getHours())}:${pad(now.getMinutes())}`;
  const displayName = nickname ?? 'gympick_user';

  // 근육 라벨
  const muscleCounts = exercises.reduce<Record<string, number>>((acc, ex) => {
    acc[ex.targetMuscle] = (acc[ex.targetMuscle] ?? 0) + 1;
    return acc;
  }, {});
  const sortedMuscles = Object.entries(muscleCounts)
    .sort(([, a], [, b]) => b - a)
    .map(([m]) => m);
  const muscleLabel = sortedMuscles.length > 1
    ? sortedMuscles.slice(0, 2).join(' + ')
    : `${sortedMuscles[0] ?? 'WORKOUT'} Day`;

  // 로고 위치 계산 (PostWorkoutLogModal과 동일 로직)
  const TL_VISUAL_X = LOGO_EDGE_GAP;
  const TL_VISUAL_Y = OVERLAY_PAD;
  const logoTlLeft  = Math.round(TL_VISUAL_X + LOGO_STRIP_H / 2 - LOGO_STRIP_W / 2);
  const logoTlTop   = Math.round(TL_VISUAL_Y + LOGO_STRIP_W / 2 - LOGO_STRIP_H / 2);

  const BR_VISUAL_X = PHOTO_W - LOGO_EDGE_GAP - LOGO_STRIP_H;
  const BR_VISUAL_Y = PHOTO_H - OVERLAY_PAD - LOGO_STRIP_W;
  const logoBrLeft  = Math.round(BR_VISUAL_X + LOGO_STRIP_H / 2 - LOGO_STRIP_W / 2);
  const logoBrTop   = Math.round(BR_VISUAL_Y + LOGO_STRIP_W / 2 - LOGO_STRIP_H / 2);

  const tc = textColor;

  // 탭 촬영
  const handleTap = useCallback(async () => {
    if (capturing || !captureAreaRef.current) return;
    setCapturing(true);
    try {
      await new Promise(resolve => requestAnimationFrame(resolve));
      const uri = await captureRef(captureAreaRef, {
        format:  'webp',
        quality: 0.9,
        result:  'tmpfile',
      });
      onCaptureDone(uri);
    } catch (e) {
      console.error('[WorkoutCameraOverlay] 촬영 오류:', e);
      setCapturing(false);
    }
  }, [capturing, onCaptureDone]);

  // 권한 요청 전
  if (!permission) {
    return (
      <View style={styles.container}>
        <ActivityIndicator color={C.accent} />
      </View>
    );
  }

  if (!permission.granted) {
    return (
      <View style={styles.container}>
        <Ionicons name="camera-outline" size={48} color={C.textDim} />
        <Text style={styles.permText}>카메라 권한이 필요합니다</Text>
        <TouchableOpacity style={styles.permBtn} onPress={requestPermission} activeOpacity={0.85}>
          <Text style={styles.permBtnText}>권한 허용</Text>
        </TouchableOpacity>
        <TouchableOpacity style={styles.cancelBtn} onPress={onCancel} activeOpacity={0.8}>
          <Text style={styles.cancelBtnText}>취소</Text>
        </TouchableOpacity>
      </View>
    );
  }

  return (
    <View style={styles.container}>
      {/* 촬영 힌트 */}
      <Text style={styles.hint}>화면을 탭하여 촬영</Text>

      {/* 캡처 대상 영역: CameraView + 오버레이 */}
      <TouchableOpacity
        activeOpacity={1}
        onPress={handleTap}
        style={{ borderRadius: 20, overflow: 'hidden' }}
        disabled={capturing}
      >
        <View
          ref={captureAreaRef}
          collapsable={false}
          style={[styles.cameraWrap, { height: PHOTO_H }]}
        >
          {/* 실제 카메라 피드 */}
          <CameraView
            style={StyleSheet.absoluteFill}
            facing="back"
            flash={flash}
          />

          {/* 오버레이: pointerEvents none → 터치가 CameraView 아닌 TouchableOpacity로 전달 */}
          <View style={StyleSheet.absoluteFill} pointerEvents="none">

            {/* 좌상단 로고 (90° CW) */}
            <View style={[styles.logoAbsolute, { left: logoTlLeft, top: logoTlTop, transform: [{ rotate: '90deg' }] }]}>
              <GymPickLogo color={tc} width={LOGO_STRIP_W} height={LOGO_STRIP_H} />
            </View>

            {/* 우하단 로고 (270° CW) */}
            <View style={[styles.logoAbsolute, { left: logoBrLeft, top: logoBrTop, transform: [{ rotate: '270deg' }] }]}>
              <GymPickLogo color={tc} width={LOGO_STRIP_W} height={LOGO_STRIP_H} />
            </View>

            {/* 우상단: 닉네임 + 타임스탬프 */}
            <View style={styles.topRight}>
              <Text style={[styles.username,  { color: tc }]}>{displayName}</Text>
              <Text style={[styles.timestamp, { color: tc }]}>{timestamp}</Text>
            </View>

            {/* 좌하단: 근육 라벨 + 운동 목록 */}
            <View style={styles.bottomLeft}>
              <Text style={[styles.muscleTitle, { color: tc }]}>{muscleLabel}</Text>
              {exercises.slice(0, 7).map(ex => {
                const sets     = logs[ex.id] ?? [];
                const setsLine = sets.map(st => `${st.weight} x ${st.reps}`).join(' / ');
                return (
                  <View key={ex.id} style={styles.exBlock}>
                    <Text style={[styles.exName, { color: tc }]} numberOfLines={1}>
                      {`[${ex.brand.toUpperCase()}] ${ex.name.toUpperCase()}`}
                    </Text>
                    {setsLine ? (
                      <Text style={[styles.exSet, { color: tc }]} numberOfLines={2}>
                        {setsLine}
                      </Text>
                    ) : null}
                  </View>
                );
              })}
              {exercises.length > 7 && (
                <Text style={[styles.exName, { color: tc, opacity: 0.6, marginTop: 2 }]}>
                  {`+${exercises.length - 7} more...`}
                </Text>
              )}
            </View>

            {/* 테두리 */}
            <View style={[styles.border, { borderColor: tc }]} pointerEvents="none" />

            {/* 촬영 중 딤 */}
            {capturing && (
              <View style={styles.capturingDim}>
                <ActivityIndicator color={C.accent} size="large" />
              </View>
            )}
          </View>
        </View>
      </TouchableOpacity>

      {/* 하단 컨트롤: 플래시 + 취소 */}
      <View style={styles.controls}>
        <TouchableOpacity
          style={styles.cancelRowBtn}
          onPress={onCancel}
          activeOpacity={0.8}
        >
          <Ionicons name="chevron-back" size={18} color={C.text} />
          <Text style={styles.cancelRowBtnText}>돌아가기</Text>
        </TouchableOpacity>

        <TouchableOpacity
          style={[styles.flashBtn, flash === 'on' && styles.flashBtnOn]}
          onPress={() => setFlash(f => f === 'off' ? 'on' : 'off')}
          activeOpacity={0.8}
        >
          <Ionicons
            name={flash === 'on' ? 'flash' : 'flash-off'}
            size={18}
            color={flash === 'on' ? C.bg : C.text}
          />
          <Text style={[styles.flashBtnText, flash === 'on' && { color: C.bg }]}>
            {flash === 'on' ? '플래시 ON' : '플래시 OFF'}
          </Text>
        </TouchableOpacity>
      </View>
    </View>
  );
}
```

주의: handleCapture 함수 전체를 아래와 같이 교체한다.
기존 handleCapture 함수 전체(async function handleCapture 부터 닫는 } 까지)를 찾아서 아래로 교체:

```tsx
  async function handleCapture(_aspect: [number, number] = [3, 4]) {
    const { status } = await ImagePicker.requestMediaLibraryPermissionsAsync();
    if (status !== 'granted') {
      Alert.alert('권한 필요', '사진 라이브러리 접근 권한이 필요합니다.');
      return;
    }
    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ['images'],
      allowsEditing: false,
      quality: 0.9,
      exif: true,
    });
    if (!result.canceled && result.assets[0]) {
      const asset = result.assets[0];

      // 당일 촬영 사진만 허용
      const today = new Date();
      today.setHours(0, 0, 0, 0);

      let photoDate: Date | null = null;
      if (asset.exif?.DateTimeOriginal) {
        const raw = asset.exif.DateTimeOriginal as string;
        const [datePart, timePart] = raw.split(' ');
        const [y, m, d] = datePart.split(':');
        photoDate = new Date(`${y}-${m}-${d}T${timePart}`);
      } else if ((asset as any).creationTime) {
        photoDate = new Date((asset as any).creationTime);
      }

      if (photoDate && photoDate < today) {
        Alert.alert('오늘 사진만 가능해요', '운동 당일 촬영한 사진만 업로드할 수 있어요.');
        return;
      }

      setPhotoUri(asset.uri);
      setPhotoTaken(true);
    }
  }
```

## 4단계: app.json 카메라 권한 추가 확인

`app.json`의 `expo.ios.infoPlist`에 아래가 없으면 추가:
```json
"NSCameraUsageDescription": "운동 인증샷 촬영을 위해 카메라 접근이 필요합니다."
```

`expo.android.permissions` 배열에 없으면 추가:
```json
"CAMERA"
```

## 5단계: 동작 확인 체크리스트

1. 오운완 사진 단계에서 점선 카드 탭 → Alert ("카메라로 찍기" / "사진 선택") 표시
2. "카메라로 찍기" 탭 → 점선 카드 자리에 인앱 카메라 뷰파인더 표시
3. 카메라 피드 위에 오버레이 요소 (닉네임, 날짜, 운동 목록, 로고) 실시간 표시
4. 하단 플래시 OFF/ON 버튼 탭 → 플래시 상태 전환
5. 카메라 영역 탭 → 촬영 → 촬영 중 딤 표시 → 완료 후 기존 오버레이 미리보기 화면으로 전환
6. "돌아가기" 탭 → 카메라 닫히고 점선 카드로 복귀
7. "사진 선택" 탭 → 기존 갤러리 선택 방식 그대로 동작
8. 다시 찍기 탭 → Alert ("카메라로 찍기" / "사진 선택") 표시
9. 텍스트 색상 변경 → 카메라 오버레이 실시간 색상 반영 (오버레이는 textColor prop으로 받음)

## 주의사항

- WorkoutCameraOverlay는 모듈 레벨에서 정의된 독립 컴포넌트 (함수 내부 정의 금지)
- captureRef 대상(captureAreaRef)은 반드시 collapsable={false} 설정
- CameraView는 captureAreaRef 안에 있어야 카메라 피드가 캡처됨
- 오버레이 View는 pointerEvents="none" → 터치가 CameraView 아닌 TouchableOpacity로 전달
- handleCapture의 Alert 분기는 WorkoutPhotoStep으로 이동했으므로 handleCapture에서 제거
