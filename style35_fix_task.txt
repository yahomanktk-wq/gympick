## STEP 1: SportypoReguler 폰트 useFonts에 추가

`src/screens/flow/PostWorkoutLogModal.tsx` 에서
`useFonts` 훅을 찾아서 `SportypoReguler` 항목을 추가한다.

기존:
```tsx
const [fontsLoaded] = useFonts({
  'MatchaCih':         require('../../../assets/fonts/Matcha_Cih.ttf'),
  'MatSaleh':          require('../../../assets/fonts/Mat_Saleh.ttf'),
  'KCCGanpan':         require('../../../assets/fonts/KCC-Ganpan.ttf'),
  'QuicksilverItalic': require('../../../assets/fonts/Quicksilver_Italic.ttf'),
});
```

변경 후:
```tsx
const [fontsLoaded] = useFonts({
  'MatchaCih':         require('../../../assets/fonts/Matcha_Cih.ttf'),
  'MatSaleh':          require('../../../assets/fonts/Mat_Saleh.ttf'),
  'KCCGanpan':         require('../../../assets/fonts/KCC-Ganpan.ttf'),
  'QuicksilverItalic': require('../../../assets/fonts/Quicksilver_Italic.ttf'),
  'SportypoReguler':   require('../../../assets/fonts/Sportypo-Reguler-Demo.ttf'),
});
```

## STEP 2: GridOverlay (스타일 3) 타겟부위 크기 30% 증가

`GridOverlay` 함수 내부에서 muscleLabel을 렌더링하는 Text를 찾는다.

찾는 코드:
```tsx
style={{
  fontSize: 20,
  fontWeight: '900',
  color: tc,
  letterSpacing: -0.5,
  textAlign: 'center',
  fontFamily: 'QuicksilverItalic',
}}
```

`fontSize: 20` 을 `fontSize: 26` 으로 변경한다:
```tsx
style={{
  fontSize: 26,
  fontWeight: '900',
  color: tc,
  letterSpacing: -0.5,
  textAlign: 'center',
  fontFamily: 'QuicksilverItalic',
}}
```

## STEP 3: GridOverlay (스타일 3) 하단 로고 크기 20% 축소

`GridOverlay` 함수 내부에서 하단 GymPickLogo 를 찾는다.

찾는 코드:
```tsx
<GymPickLogo color={tc} width={Math.round(LOGO_STRIP_W * 0.85)} height={Math.round(LOGO_STRIP_H * 0.85)} />
```

`0.85` 를 `0.68` 로 변경한다 (0.85 × 0.8 = 0.68):
```tsx
<GymPickLogo color={tc} width={Math.round(LOGO_STRIP_W * 0.68)} height={Math.round(LOGO_STRIP_H * 0.68)} />
```

## STEP 4: SidebarOverlay (스타일 5) 타겟부위 밑줄 제거 + 폰트 변경

`SidebarOverlay` 함수 내부에서 muscleLabel을 렌더링하는 Text를 찾는다.
세로 회전된 타겟부위 텍스트로 `transform: [{ rotate: '90deg' }]` 가 포함되어 있다.

찾는 스타일 내에서:
- `textDecorationLine: 'underline'` 이 있으면 제거
- `fontFamily` 를 `'SportypoReguler'` 로 추가 또는 변경

최종 muscleLabel Text 스타일:
```tsx
style={{
  fontSize: 26,
  fontWeight: '900',
  color: tc,
  transform: [{ rotate: '90deg' }],
  width: photoH * 0.35,
  textAlign: 'center',
  letterSpacing: -0.3,
  fontFamily: 'SportypoReguler',
}}
```
