[5단계] 같은 머신 두 번 기록 — 복합키 구조 전환
================================================================================
※ 운동기록 핵심 자료구조 변경. 가장 위험한 작업. OLD/NEW 정확히 지킬 것.
※ 변경 후 반드시 디바이스 테스트 (저장→재조회→두 줄 확인).

■ 목표
운동일지에서 같은 머신(A)을 두 번 나눠 기록 가능하게.
A → B → C → A 처럼 A가 두 줄로 나열되고, 각각 독립된 세트를 가짐.

■ 핵심 설계
- 복합키: `machineId + '#' + slot`  예) 'm02#0', 'm02#1', 'fw01#0'
  ★ 구분자는 반드시 '#'. 머신 id에 '_'가 많아('cybex_etc_1') '_'로 자르면 깨짐.
- 한 번만 한 머신도 내부적으로 '#0' 슬롯을 가짐. 화면엔 ex.name(머신명)만 표시되므로
  복합키는 노출되지 않음 (그냥 "A"로 보임).
- 같은 머신 두 번 → 화면에 "A"가 두 줄 (구분표시 없음 — 결정대로).

■ UX (옵션 2)
머신 카드 탭 시:
  · 그 머신이 아직 기록 안 됨 → 첫 슬롯 'machineId#0' 생성, 세트 입력으로.
  · 이미 기록됨 → Alert "이미 기록한 머신이에요"
       - "기존 수정" → 가장 마지막 슬롯 열기
       - "새로 추가" → 새 슬롯 'machineId#N' 생성, 세트 입력으로.

  // 복합키('m02#1')에서 순수 machineId('m02') 추출. 슬롯 없으면 그대로.
  function machineIdFromKey(key: string): string {
    const i = key.lastIndexOf('#');
    return i === -1 ? key : key.slice(0, i);
  }

  // 특정 머신의 현재 슬롯 키들 (loggedIds + 현재 선택 중 포함). 정렬된 배열 반환.
  function slotKeysForMachine(machineId: string): string[] {
    const keys: string[] = [];
    for (const k of loggedIds) {
      if (machineIdFromKey(k) === machineId) keys.push(k);
    }
    return keys.sort();
  }

  function handleSelectExercise(id: string) {
    // id = 순수 machineId
    const existing = slotKeysForMachine(id); // 이미 기록된 이 머신의 슬롯들
    if (existing.length === 0) {
      // 첫 기록 → 슬롯 0
      openNewSlot(id, `${id}#0`, true);
      return;
    }
    // 이미 기록됨 → 수정 vs 새로 추가
    Alert.alert(
      '이미 기록한 머신이에요',
      '기존 기록을 수정하거나 새로 추가할 수 있어요.',
      [
        {
          text: '기존 수정',
          onPress: () => {
            const lastKey = existing[existing.length - 1]; // 마지막 슬롯
            setCurrentExerciseId(lastKey);
            setStep('log-sets');
          },
        },
        {
          text: '새로 추가',
          onPress: () => {
            // 다음 슬롯 번호 = 기존 슬롯들의 최대 슬롯+1
            const maxSlot = existing.reduce((mx, k) => {
              const n = parseInt(k.slice(k.lastIndexOf('#') + 1), 10);
              return isNaN(n) ? mx : Math.max(mx, n);
            }, -1);
            openNewSlot(id, `${id}#${maxSlot + 1}`, false); // 추가 슬롯은 프리필 안 함
          },
        },
        { text: '취소', style: 'cancel' },
      ],
    );
  }

- "새로 추가" → A 두 번째 슬롯 세트 입력(프리필 없이 60×10) → 저장
  → 운동 종료 화면(요약)에 A가 두 줄로, 각각 다른 세트로 보이는지
- 운동 종료 카운트가 슬롯 수(A 2개면 +2)로 맞는지
- 인증샷 생성 → 오버레이에 A가 두 줄(각자 세트)로 찍히는지, 복합키('m02#1') 노출 안 되는지
- 저장 후 운동일지(Journal)에서 그 세션 열기 → A가 두 entry로 보이는지 (DB 저장 확인)
- "기존 수정" 선택 시 마지막 슬롯 세트가 그대로 열리는지
- 한 번만 한 머신은 그냥 "A"로(번호 없이) 보이는지
- 프리웨이트(fw)도 동일하게 두 번 추가되는지
