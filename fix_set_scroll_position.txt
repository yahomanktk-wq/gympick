# 태스크: 세트 추가 시 스크롤 위치 정확히 보정 (수정3 재작업)

## 파일 경로
`src/screens/flow/PostWorkoutLogModal.tsx`

## 전제
이전 두 태스크가 완료된 상태:
- SetProgressBanner 컴포넌트 존재
- SetLoggingStep에 bannerHeightRef, scrollToNewSet 함수가 이미 구현되어 있음
- 이번 태스크는 수정3(스크롤 로직)만 교체한다

---

## 구현 방법

### 핵심 아이디어
새로 추가된 세트(마지막 setBlock)의 ScrollView 내 y좌표를 직접 측정해서 scrollTo한다.

React Native의 `measureLayout(relativeToNativeNode, ...)` API를 사용:
- 새 세트 View ref → `.measureLayout(scrollView node, (x, y) => scrollTo({ y }))`
- 이렇게 하면 ScrollView 내 상대 좌표를 정확히 얻을 수 있음

## 변경 상세

### 1. SetCard에 새 세트 ref 콜백 prop 추가

SetCard props에 `onLastSetRef` 추가:

```ts
// 변경 전
function SetCard({ ex, sets, onChange, onAdd, onCopyPrev, onRemove }: {
  ex: ExerciseInfo;
  sets: SetEntry[];
  onChange: (idx: number, field: keyof SetEntry, val: number) => void;
  onAdd: () => void;
  onCopyPrev: () => void;
  onRemove: (idx: number) => void;
})

// 변경 후
function SetCard({ ex, sets, onChange, onAdd, onCopyPrev, onRemove, onLastSetRef }: {
  ex: ExerciseInfo;
  sets: SetEntry[];
  onChange: (idx: number, field: keyof SetEntry, val: number) => void;
  onAdd: () => void;
  onCopyPrev: () => void;
  onRemove: (idx: number) => void;
  onLastSetRef?: (node: View | null) => void;
})
```

### 2. SetCard 내 마지막 setBlock에 ref 연결

sets.map 렌더링 부분에서 마지막 항목(idx === sets.length - 1)에만 ref를 붙인다:

```tsx
// 변경 전
{sets.map((set, idx) => (
  <View key={idx} style={s.setBlock}>

// 변경 후
{sets.map((set, idx) => (
  <View
    key={idx}
    style={s.setBlock}
    ref={idx === sets.length - 1 ? onLastSetRef : undefined}
  >
```

### 3. SetLoggingStep 수정

#### 추가할 import (이미 있으면 스킵)
View를 react-native import에서 이미 가져오고 있으므로 추가 import 없음.

#### SetLoggingStep 내부 ref 및 스크롤 로직 교체

기존의 `bannerHeightRef`와 `scrollToNewSet` 함수를 아래로 교체한다:

```tsx
// 기존 코드 제거:
// const bannerHeightRef = useRef<number>(0);
// function scrollToNewSet() {
//   setTimeout(() => {
//     const targetY = bannerHeightRef.current + 140;
//     scrollRef.current?.scrollTo({ y: targetY, animated: true });
//   }, 100);
// }

// 새 코드로 교체:
const lastSetNodeRef = useRef<View | null>(null);

function handleLastSetRef(node: View | null) {
  lastSetNodeRef.current = node;
}

function scrollToNewSet() {
  setTimeout(() => {
    const scrollNode = scrollRef.current?.getScrollableNode?.();
    const setNode    = lastSetNodeRef.current;
    if (!scrollNode || !setNode) {
      // fallback: 측정 실패 시 scrollToEnd
      scrollRef.current?.scrollToEnd({ animated: true });
      return;
    }
    // @ts-ignore: measureLayout은 타입 정의가 불완전하지만 RN에서 동작함
    setNode.measureLayout(
      scrollNode,
      (_x: number, y: number) => {
        scrollRef.current?.scrollTo({ y, animated: true });
      },
      () => {
        // 측정 실패 fallback
        scrollRef.current?.scrollToEnd({ animated: true });
      },
    );
  }, 100);
}
```

## 동작 원리 설명
1. 세트 추가/복사 → state 업데이트 → React가 새 setBlock을 렌더링
2. 100ms 후 `handleLastSetRef`에 저장된 새 세트 View node가 준비된 상태
3. `measureLayout(scrollNode, ...)` 호출 → ScrollView 내 y좌표 반환
4. `scrollTo({ y })` → 새 세트 최상단이 화면 최상단(= 배너 바로 아래)으로 이동
5. 배너는 ScrollView 밖(SafeAreaView 직속)에 고정되어 있으므로 스크롤해도 위치 유지

1. 세트 1개 상태에서 "세트 추가" 탭 → 새 세트(세트2) 최상단이 배너 하단에 딱 붙어 표시
2. 세트 2개 상태에서 "이전 세트 복사" 탭 → 새 세트(세트3) 최상단이 배너 하단에 표시
3. 완료 세트가 없을 때(세트 1개) → 배너 없으므로 스크롤 위치 기존과 동일(fallback scrollToEnd)
4. measureLayout 실패 시 scrollToEnd로 fallback 처리됨
5. 타입스크립트 에러 없음 (@ts-ignore 1개는 허용)
