# 태스크: 세트 기록 화면 — 진행 세트 요약 배너 추가

## 파일 경로
`src/screens/flow/PostWorkoutLogModal.tsx`

## 목표
세트 기록 화면(SetLoggingStep)의 StepBar 바로 아래에,
현재 머신에서 이미 완료(추가)된 세트들의 요약을 세로 리스트 형태로 표시한다.

---

## 규칙
1. SetLoggingStep 컴포넌트만 수정한다 (다른 컴포넌트 변경 금지)
2. 스타일은 기존 C, R, T theme 시스템 사용
3. 읽기 전용 UI (탭해도 아무 동작 없음)
4. 완료된 세트가 수정되면 실시간으로 반영됨 (sets prop이 변하면 자동 반영)
5. 완료된 세트가 0개일 때는 배너 자체를 렌더링하지 않음

---

## 변경 상세

### 1. "완료된 세트" 정의
`sets` 배열에서 **마지막 세트(현재 입력 중)를 제외한 나머지**를 완료된 세트로 간주한다.

```ts
const completedSets = sets.slice(0, -1);
```

세트가 1개일 때는 완료 세트 없음 → 배너 미표시.
세트가 2개 이상일 때 → 첫 번째 세트부터 마지막-1까지 표시.

### 2. SetLoggingStep 컴포넌트 수정 (line 839~918)

SetLoggingStep 함수 내부에서 completedSets를 계산하고,
StepBar와 ScrollView 사이에 SetProgressBanner를 삽입한다.

수정 전:
```tsx
return (
  <SafeAreaView style={s.safe}>
    <NavHeader title="세트 기록" onBack={onBack} onClose={onClose} />
    <StepBar total={5} current={2} />
    <ScrollView ref={scrollRef} ...>
```

수정 후:
```tsx
const completedSets = sets.slice(0, -1);

return (
  <SafeAreaView style={s.safe}>
    <NavHeader title="세트 기록" onBack={onBack} onClose={onClose} />
    <StepBar total={5} current={2} />
    {completedSets.length > 0 && (
      <SetProgressBanner sets={completedSets} />
    )}
    <ScrollView ref={scrollRef} ...>
```

### 3. SetProgressBanner 컴포넌트 추가 (모듈 레벨에 정의)

반드시 **모듈 레벨(함수 외부)**에 정의할 것 (한글 IME 버그 방지 원칙).

SetCard 컴포넌트(line 718) 바로 위에 추가한다.

```tsx
// --- Set Progress Banner (완료된 세트 요약 — SetLoggingStep 상단에 표시)

function SetProgressBanner({ sets }: { sets: SetEntry[] }) {
  return (
    <View style={s.setProgressBanner}>
      <View style={s.setProgressHeader}>
        <Ionicons name="checkmark-circle" size={13} color={C.accent} />
        <Text style={s.setProgressHeaderText}>완료된 세트</Text>
        <View style={s.setProgressCountBadge}>
          <Text style={s.setProgressCountText}>{sets.length}</Text>
        </View>
      </View>
      <View style={s.setProgressList}>
        {sets.map((set, idx) => (
          <View key={idx} style={s.setProgressRow}>
            <View style={s.setProgressIndex}>
              <Text style={s.setProgressIndexText}>{idx + 1}</Text>
            </View>
            <View style={s.setProgressKgBlock}>
              <Text style={s.setProgressKgValue}>{set.weight}</Text>
              <Text style={s.setProgressKgUnit}>kg</Text>
            </View>
            <View style={s.setProgressSeparator}>
              <Text style={s.setProgressSeparatorText}>×</Text>
            </View>
            <View style={s.setProgressRepsBlock}>
              <Text style={s.setProgressRepsValue}>{set.reps}</Text>
              <Text style={s.setProgressRepsUnit}>reps</Text>
            </View>
          </View>
        ))}
      </View>
    </View>
  );
}
```

### 5. setProgressRow 마지막 항목 borderBottom 제거

SetProgressBanner 컴포넌트의 map 렌더링 부분을 아래처럼 수정해서
마지막 행에 borderBottom이 없도록 한다:

```tsx
{sets.map((set, idx) => (
  <View
    key={idx}
    style={[
      s.setProgressRow,
      idx === sets.length - 1 && { borderBottomWidth: 0 },
    ]}
  >
    ...
  </View>
))}
```

## 검증 포인트
1. 세트가 1개일 때 → 배너 미표시
2. 세트 추가 버튼 탭 → 이전 세트가 배너에 즉시 추가됨
3. 이전 세트 복사 탭 → 복사된 세트가 배너에 즉시 추가됨
4. 완료된 세트의 kg/reps를 수정하면 배너에도 실시간 반영됨
5. "저장하고 다음 머신" 탭 후 새 머신 진입 시 → 배너 초기화(빈칸)
6. 타입스크립트 에러 없음
