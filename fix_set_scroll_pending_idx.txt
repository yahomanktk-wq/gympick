# 태스크: 세트 스크롤 — 새 세트 onLayout 완료 후 스크롤 (인덱스 기반 대기)

## 파일 경로
`src/screens/flow/PostWorkoutLogModal.tsx`

## 문제
세트 추가/복사 탭 시 직전 세트(완료된 세트 마지막)로 스크롤되고 있음.
원인: scrollToNewSet 실행 시점에 새 세트 onLayout이 아직 미완료 상태.

## 해결 방법
"추가 직전 세트 수"를 pendingScrollIdx ref에 저장해두고,
SetCard의 onSetLayout 콜백에서 해당 인덱스의 레이아웃이 들어오는 순간 scrollTo 실행.
타이머 기반 스크롤 완전 제거.

---

## 변경 상세

### SetLoggingStep 내부 전면 교체

기존의 scrollToNewSet 함수와 handleAdd/handleCopyPrev를 아래로 교체한다.

#### 제거할 코드
```tsx
// 아래 함수들 전부 제거
function scrollToNewSet() { ... }
function handleAdd() { onAdd(); scrollToNewSet(); }
function handleCopyPrev() { Haptics...; onCopyPrev(); scrollToNewSet(); }
```

#### 교체할 코드

```tsx
// setLayoutsRef: 각 setBlock의 y좌표 (기존 유지)
const setLayoutsRef    = useRef<number[]>([]);
// pendingScrollIdx: 스크롤 대기 중인 새 세트 인덱스 (-1이면 대기 없음)
const pendingScrollIdx = useRef<number>(-1);

function handleSetLayout(idx: number, y: number) {
  setLayoutsRef.current[idx] = y;
  // 이 인덱스가 대기 중이던 새 세트라면 즉시 스크롤
  if (pendingScrollIdx.current === idx) {
    pendingScrollIdx.current = -1;
    scrollRef.current?.scrollTo({ y, animated: true });
  }
}

function handleAdd() {
  // 추가 전 세트 수 = 새 세트가 가질 인덱스
  pendingScrollIdx.current = sets.length;
  onAdd();
}

function handleCopyPrev() {
  Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
  // 추가 전 세트 수 = 새 세트가 가질 인덱스
  pendingScrollIdx.current = sets.length;
  onCopyPrev();
}
```

### SetCard의 onSetLayout 호출부는 변경 없음
기존 코드 그대로 유지:
```tsx
onLayout={(e) => onSetLayout?.(idx, e.nativeEvent.layout.y)}
```

### SetCard 호출부도 변경 없음
```tsx
<SetCard
  ...
  onSetLayout={handleSetLayout}
/>
```

---

## 동작 원리

1. 세트 추가 탭
   → `pendingScrollIdx.current = sets.length` (새 세트가 가질 인덱스 저장)
   → `onAdd()` → state 업데이트 → React 리렌더링
2. 새 setBlock View가 네이티브 레이아웃 완료
   → `onLayout` 콜백 실행 → `handleSetLayout(newIdx, y)` 호출
3. `pendingScrollIdx.current === newIdx` 조건 충족
   → 즉시 `scrollRef.current?.scrollTo({ y, animated: true })`
4. 새 세트 최상단이 배너 하단으로 정확히 스크롤됨
5. 타이머 없음, measureLayout 없음 → 에러 없음, 타이밍 이슈 없음

---

## 검증 포인트
1. 세트 추가 탭 → 새로 생성된 세트(예: 세트4) 최상단이 배너 하단으로 스크롤됨
2. 이전 세트 복사 탭 → 동일하게 동작
3. 직전 세트(완료 세트)로 스크롤되는 현상 없음
4. 터미널에 measureLayout 관련 에러 없음
5. 타입스크립트 에러 없음
