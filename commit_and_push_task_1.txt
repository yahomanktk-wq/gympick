[클로드 코드 작업 지시서 — 커밋 & 푸시]

확인이나 중단 없이 끝까지 완료해줘. 단, 아래 "사전 확인"에서 상태가 예상과 다르면
그 단계에서 멈추고 무엇이 다른지 보고해줘 (임의로 판단해서 진행하지 말 것).

## 목표
이번 세션에서 수정된 아래 6개 파일만 정확히 커밋하고 원격에 푸시한다.

## 1단계 — 사전 확인
`git status`를 실행해서 변경 내역을 확인한다. 다음과 일치해야 한다:
- modified: App.tsx
- modified: app.json
- modified: package.json
- modified: src/screens/flow/PostWorkoutLogModal.tsx
- untracked (new file): src/lib/db/appUpdate.ts
- untracked (new file): src/components/AppUpdateModal.tsx
- untracked (new file): commit_message_task.txt, commit_and_push_task.txt (이 두 파일은
  .gitignore의 *_task.txt 패턴에 걸려서 git status에 아예 안 보이는 게 정상 — 혹시 보이면
  그것도 커밋 대상에서 반드시 제외할 것)

위 6개 파일(App.tsx, app.json, package.json, PostWorkoutLogModal.tsx, appUpdate.ts,
AppUpdateModal.tsx) 외에 의도치 않은 다른 변경사항이나 새 파일이 섞여 있다면, 진행하지
말고 어떤 파일들이 더 있는지 목록으로 보고하고 멈출 것.

app.json의 "version"이 "1.2.1", ios.buildNumber가 "39", android.versionCode가 20인지,
package.json의 "version"도 "1.2.1"인지 확인할 것. 다르면 멈추고 보고.

## 2단계 — expo-constants 설치 확인
package.json의 dependencies에 "expo-constants"가 이미 있는지 확인한다.
- 없다면: `npx expo install expo-constants` 실행. 이 명령으로 package.json과
  package-lock.json(또는 yarn.lock)이 추가로 바뀔 수 있는데, 바뀌었다면 이것도 3단계
  git add 대상에 포함시킬 것.
- 이미 있다면: 이 단계는 건너뛴다.

## 3단계 — 스테이징
아래 파일만 정확히 add한다. `git add -A`나 `git add .`는 절대 사용하지 말 것.

```
git add App.tsx app.json package.json src/lib/db/appUpdate.ts src/components/AppUpdateModal.tsx src/screens/flow/PostWorkoutLogModal.tsx
```

(2단계에서 package-lock.json/yarn.lock이 바뀌었다면 그 파일도 위 명령에 추가)

## 4단계 — 커밋
레포 루트에 이미 준비되어 있는 커밋 메시지 파일을 사용한다 (직접 -m으로 타이핑하지 말 것):

```
git commit -F commit_message_task.txt
```

## 5단계 — 푸시
```
git push
```

## 완료 후
커밋 해시(짧은 hash)와 push 결과(정상적으로 원격에 반영됐는지)를 보고해줘.
