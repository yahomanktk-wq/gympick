## STEP 1: QuicksilverItalic 폰트 useFonts에 추가

`src/screens/flow/PostWorkoutLogModal.tsx` 에서
`useFonts` 훅을 찾아서 `QuicksilverItalic` 항목을 추가한다.

기존:
```tsx
const [fontsLoaded] = useFonts({
  'MatchaCih':  require('../../../assets/fonts/Matcha_Cih.ttf'),
  'MatSaleh':   require('../../../assets/fonts/Mat_Saleh.ttf'),
  'KCCGanpan':  require('../../../assets/fonts/KCC-Ganpan.ttf'),
});
```

변경 후:
```tsx
const [fontsLoaded] = useFonts({
  'MatchaCih':         require('../../../assets/fonts/Matcha_Cih.ttf'),
  'MatSaleh':          require('../../../assets/fonts/Mat_Saleh.ttf'),
  'KCCGanpan':         require('../../../assets/fonts/KCC-Ganpan.ttf'),
  'QuicksilverItalic': require('../../../assets/fonts/Quicksilver_Italic.ttf'),
});
```

이미 `QuicksilverItalic` 가 있으면 추가 불필요.

## STEP 2: ClassicOverlay (스타일 1) 타겟부위 폰트 적용

`ClassicOverlay` 함수 내부에서 아래 코드를 찾는다:

```tsx
<Text style={[s.overlayMuscleTitle, { color: tc }]}>{muscleLabel}</Text>
```

아래로 교체:
```tsx
<Text style={[s.overlayMuscleTitle, { color: tc, fontFamily: 'QuicksilverItalic' }]}>{muscleLabel}</Text>
```

## STEP 3: LeftColOverlay (스타일 2) 타겟부위 밑줄 제거 + 폰트 적용

`LeftColOverlay` 함수 내부에서 muscleLabel을 렌더링하는 Text를 찾는다.
`textDecorationLine: 'underline'` 이 포함된 Text 이다.

찾는 코드 (정확한 형태가 다를 수 있으므로 muscleLabel 을 렌더링하는 Text 를 찾아 수정):
```tsx
style={{
  fontSize: 22,
  fontWeight: '900',
  color: tc,
  letterSpacing: -0.5,
  textDecorationLine: 'underline',
}}
```

`textDecorationLine: 'underline'` 을 제거하고 `fontFamily: 'QuicksilverItalic'` 을 추가한다:
```tsx
style={{
  fontSize: 22,
  fontWeight: '900',
  color: tc,
  letterSpacing: -0.5,
  fontFamily: 'QuicksilverItalic',
}}
```

## STEP 4: GridOverlay (스타일 3) 타겟부위 밑줄 제거 + 폰트 적용

`GridOverlay` 함수 내부에서 muscleLabel을 렌더링하는 Text를 찾는다.
`textDecorationLine: 'underline'` 이 포함된 Text 이다.

찾는 코드:
```tsx
style={{
  fontSize: 20,
  fontWeight: '900',
  color: tc,
  letterSpacing: -0.5,
  textDecorationLine: 'underline',
  textAlign: 'center',
}}
```

`textDecorationLine: 'underline'` 을 제거하고 `fontFamily: 'QuicksilverItalic'` 을 추가한다:
```tsx
style={{
  fontSize: 20,
  fontWeight: '900',
  color: tc,
  letterSpacing: -0.5,
  textAlign: 'center',
  fontFamily: 'QuicksilverItalic',
}}
```
