## 목표

오운완 사진 단계에서 오버레이 레이아웃 스타일을 3종 중 선택할 수 있게 한다.
스타일 선택 UI는 컬러칩 위에 배치한다.
텍스트 색상은 기존과 동일하게 textColor(컬러칩) 값을 따른다.

---

## 3가지 스타일 정의

### Style 1: Classic (기존 유지)
- 좌하단: muscleLabel 대제목 + [브랜드] 머신명 + 세트 슬래시 나열
- 우상단: 닉네임 + 타임스탬프
- 좌우 세로 GymPick 로고

### Style 2: Left Column (새로 추가 — Image 2 기준)
레이아웃:
- 좌상단: 타겟부위_day (대제목, 언더라인)
- 우상단: 닉네임 + 타임스탬프 (우측 정렬, 줄바꿈)
- 좌측 세로: [브랜드] → 머신명 → S1 60kg × 10 → S2 60kg × 10 ... 순서로 머신별 블록
- 우하단: GYM PICK 로고

### Style 3: Grid (새로 추가 — Image 1 기준)
레이아웃:
- 상단: 닉네임 (좌), 타임스탬프 (우)
- 중앙 상단: 타겟부위_day (중앙, 언더라인)
- 중앙: 머신 3열 그리드 ([브랜드] / 머신명 / S1 60kg × 10 / S2 ...)
- 하단 중앙: GYM PICK 로고

WorkoutPhotoStep 함수 바깥, 모듈 레벨에 아래 컴포넌트들을 추가한다.

### 공통 props 타입

```tsx
interface OverlayProps {
  exercises: ExerciseInfo[];
  logs: Record<string, SetEntry[]>;
  nickname: string;
  timestamp: string;
  muscleLabel: string;
  tc: string; // textColor
  photoW: number;
  photoH: number;
}
```

### ClassicOverlay (기존 오버레이 그대로 추출)

기존 overlayRef 내부의 오버레이 요소들을 그대로 컴포넌트로 추출한다.

```tsx
function ClassicOverlay({ exercises, logs, nickname, timestamp, muscleLabel, tc, photoW, photoH }: OverlayProps) {
  const LOGO_STRIP_H_L = 14;
  const LOGO_STRIP_W_L = Math.round(LOGO_STRIP_H_L * (2805 / 279));
  const LOGO_EDGE_GAP  = 8;

  const logoTlLeft = Math.round(LOGO_EDGE_GAP + LOGO_STRIP_H_L / 2 - LOGO_STRIP_W_L / 2);
  const logoTlTop  = Math.round(OVERLAY_PAD   + LOGO_STRIP_W_L / 2 - LOGO_STRIP_H_L / 2);
  const logoBrLeft = Math.round((photoW - LOGO_EDGE_GAP - LOGO_STRIP_H_L) + LOGO_STRIP_H_L / 2 - LOGO_STRIP_W_L / 2);
  const logoBrTop  = Math.round((photoH - OVERLAY_PAD - LOGO_STRIP_W_L)   + LOGO_STRIP_W_L / 2 - LOGO_STRIP_H_L / 2);

  return (
    <>
      {/* 좌상단 로고 90° */}
      <View style={[s.overlayLogoAbsolute, { left: logoTlLeft, top: logoTlTop, transform: [{ rotate: '90deg' }] }]}>
        <GymPickLogo color={tc} width={LOGO_STRIP_W_L} height={LOGO_STRIP_H_L} />
      </View>
      {/* 우하단 로고 270° */}
      <View style={[s.overlayLogoAbsolute, { left: logoBrLeft, top: logoBrTop, transform: [{ rotate: '270deg' }] }]}>
        <GymPickLogo color={tc} width={LOGO_STRIP_W_L} height={LOGO_STRIP_H_L} />
      </View>
      {/* 우상단: 닉네임 + 타임스탬프 */}
      <View style={s.overlayTopRight}>
        <Text style={[s.overlayUsername, { color: tc }]}>{nickname}</Text>
        <Text style={[s.overlayTimestamp, { color: tc }]}>{timestamp}</Text>
      </View>
      {/* 좌하단: muscleLabel + 운동 목록 */}
      <View style={s.overlayBottomLeft}>
        <Text style={[s.overlayMuscleTitle, { color: tc }]}>{muscleLabel}</Text>
        <View style={s.sessionScroll}>
          {exercises.slice(0, 7).map(ex => {
            const sets     = logs[ex.id] ?? [];
            const setsLine = sets.map(st => `${st.weight} x ${st.reps}`).join(' / ');
            return (
              <View key={ex.id} style={s.overlayExBlock}>
                <Text style={[s.overlayExName, { color: tc }]} numberOfLines={1}>
                  {`[${ex.brand.toUpperCase()}] ${ex.name.toUpperCase()}`}
                </Text>
                {setsLine ? (
                  <Text style={[s.overlayExSet, { color: tc }]} numberOfLines={2}>{setsLine}</Text>
                ) : null}
              </View>
            );
          })}
          {exercises.length > 7 && (
            <Text style={[s.overlayExName, { color: tc, opacity: 0.6, marginTop: 2 }]}>
              {`+${exercises.length - 7} more...`}
            </Text>
          )}
        </View>
      </View>
    </>
  );
}
```

### LeftColOverlay (Style 2 — Image 2 기준)

```tsx
function LeftColOverlay({ exercises, logs, nickname, timestamp, muscleLabel, tc, photoW, photoH }: OverlayProps) {
  // timestamp를 날짜/시간 두 줄로 분리
  const tsParts  = timestamp.split('_');
  const tsDate   = tsParts[0] ?? timestamp;
  const tsTime   = tsParts[1] ?? '';

  return (
    <>
      {/* 좌상단: 타겟부위_day 대제목 (언더라인) */}
      <View style={{
        position: 'absolute',
        top: OVERLAY_PAD,
        left: OVERLAY_PAD,
        right: photoW * 0.45,
      }}>
        <Text style={{
          fontSize: 22,
          fontWeight: '900',
          color: tc,
          letterSpacing: -0.5,
          textDecorationLine: 'underline',
        }} numberOfLines={2}>
          {muscleLabel}
        </Text>
      </View>

      {/* 우상단: 닉네임 + 날짜 + 시간 (우측 정렬, 줄바꿈) */}
      <View style={{
        position: 'absolute',
        top: OVERLAY_PAD,
        right: OVERLAY_PAD,
        alignItems: 'flex-end',
      }}>
        <Text style={{ fontSize: 13, fontWeight: '900', color: tc, letterSpacing: 0.3 }}>
          {nickname}
        </Text>
        <Text style={{ fontSize: 11, fontWeight: '700', color: tc, opacity: 0.85, marginTop: 2 }}>
          {tsDate}
        </Text>
        {tsTime ? (
          <Text style={{ fontSize: 11, fontWeight: '700', color: tc, opacity: 0.85 }}>
            {tsTime}
          </Text>
        ) : null}
      </View>

      {/* 좌측 세로: 머신 블록 목록 */}
      <View style={{
        position: 'absolute',
        top: OVERLAY_PAD + 52,
        left: OVERLAY_PAD,
        right: OVERLAY_PAD,
        bottom: OVERLAY_PAD + 32,
      }}>
        {exercises.slice(0, 6).map(ex => {
          const sets = logs[ex.id] ?? [];
          return (
            <View key={ex.id} style={{ marginBottom: 10 }}>
              <Text style={{ fontSize: 9, fontWeight: '700', color: tc, opacity: 0.7, letterSpacing: 0.8 }}>
                {`[${ex.brand.toUpperCase()}]`}
              </Text>
              <Text style={{ fontSize: 11, fontWeight: '900', color: tc, letterSpacing: 0.3, marginBottom: 2 }}>
                {ex.name.toUpperCase()}
              </Text>
              {sets.map((st, si) => (
                <Text key={si} style={{ fontSize: 9, fontWeight: '600', color: tc, opacity: 0.85, lineHeight: 14 }}>
                  {`S${si + 1}  ${st.weight}kg × ${st.reps}`}
                </Text>
              ))}
            </View>
          );
        })}
        {exercises.length > 6 && (
          <Text style={{ fontSize: 9, fontWeight: '700', color: tc, opacity: 0.6 }}>
            {`+${exercises.length - 6} more...`}
          </Text>
        )}
      </View>

      {/* 우하단: GYM PICK 로고 */}
      <View style={{
        position: 'absolute',
        bottom: OVERLAY_PAD,
        right: OVERLAY_PAD,
      }}>
        <GymPickLogo color={tc} width={LOGO_STRIP_W} height={LOGO_STRIP_H} />
      </View>
    </>
  );
}
```

### GridOverlay (Style 3 — Image 1 기준)

```tsx
function GridOverlay({ exercises, logs, nickname, timestamp, muscleLabel, tc, photoW, photoH }: OverlayProps) {
  const COL_COUNT  = 3;
  const COL_W      = Math.floor((photoW - OVERLAY_PAD * 2 - 16) / COL_COUNT);

  return (
    <>
      {/* 상단: 닉네임(좌) + 타임스탬프(우) */}
      <View style={{
        position: 'absolute',
        top: OVERLAY_PAD,
        left: OVERLAY_PAD,
        right: OVERLAY_PAD,
        flexDirection: 'row',
        justifyContent: 'space-between',
        alignItems: 'flex-start',
      }}>
        <Text style={{ fontSize: 13, fontWeight: '900', color: tc, letterSpacing: 0.3 }}>
          {nickname}
        </Text>
        <Text style={{ fontSize: 10, fontWeight: '700', color: tc, opacity: 0.85 }}>
          {timestamp}
        </Text>
      </View>

      {/* 중앙 상단: 타겟부위_day (중앙, 언더라인) */}
      <View style={{
        position: 'absolute',
        top: OVERLAY_PAD + 36,
        left: OVERLAY_PAD,
        right: OVERLAY_PAD,
        alignItems: 'center',
      }}>
        <Text style={{
          fontSize: 20,
          fontWeight: '900',
          color: tc,
          letterSpacing: -0.5,
          textDecorationLine: 'underline',
          textAlign: 'center',
        }}>
          {muscleLabel}
        </Text>
      </View>

      {/* 3열 그리드: 머신 블록 */}
      <View style={{
        position: 'absolute',
        top: OVERLAY_PAD + 80,
        left: OVERLAY_PAD,
        right: OVERLAY_PAD,
        bottom: OVERLAY_PAD + 32,
        flexDirection: 'row',
        flexWrap: 'wrap',
        gap: 8,
        alignContent: 'flex-start',
      }}>
        {exercises.slice(0, 9).map(ex => {
          const sets = logs[ex.id] ?? [];
          return (
            <View key={ex.id} style={{ width: COL_W, marginBottom: 12 }}>
              <Text style={{ fontSize: 8, fontWeight: '700', color: tc, opacity: 0.7, letterSpacing: 0.5 }}>
                {`[${ex.brand.toUpperCase()}]`}
              </Text>
              <Text style={{ fontSize: 9, fontWeight: '900', color: tc, letterSpacing: 0.2, marginBottom: 3, lineHeight: 13 }} numberOfLines={2}>
                {ex.name.toUpperCase()}
              </Text>
              {sets.map((st, si) => (
                <Text key={si} style={{ fontSize: 8, fontWeight: '600', color: tc, opacity: 0.85, lineHeight: 13 }}>
                  {`S${si + 1} ${st.weight}kg × ${st.reps}`}
                </Text>
              ))}
            </View>
          );
        })}
        {exercises.length > 9 && (
          <View style={{ width: COL_W }}>
            <Text style={{ fontSize: 8, fontWeight: '700', color: tc, opacity: 0.6 }}>
              {`+${exercises.length - 9} more...`}
            </Text>
          </View>
        )}
      </View>

      {/* 하단 중앙: GYM PICK 로고 */}
      <View style={{
        position: 'absolute',
        bottom: OVERLAY_PAD,
        left: 0,
        right: 0,
        alignItems: 'center',
      }}>
        <GymPickLogo color={tc} width={LOGO_STRIP_W} height={LOGO_STRIP_H} />
      </View>
    </>
  );
}
```

                logs={logs}
                nickname={displayName}
                timestamp={timestamp}
                muscleLabel={muscleLabel}
                tc={tc}

              />

            {overlayStyle === 'leftcol' && (
              <LeftColOverlay
                exercises={exercises}
                logs={logs}
                nickname={displayName}
                timestamp={timestamp}
                muscleLabel={muscleLabel}
                tc={tc}
                photoW={PHOTO_W}
                photoH={PHOTO_H}
              />
            )}
            {overlayStyle === 'grid' && (
              <GridOverlay
                exercises={exercises}
                logs={logs}

단, ClassicOverlay, LeftColOverlay, GridOverlay 컴포넌트는

PostWorkoutLogModal.tsx에서 세 컴포넌트를 export로 변경:

## 주의사항

- ClassicOverlay, LeftColOverlay, GridOverlay는 반드시 모듈 레벨에 정의 (함수 내부 정의 금지)
- 세 컴포넌트는 export로 선언해서 WorkoutCameraOverlay에서 import 가능하게
- overlayRef 내부의 기존 오버레이 요소들은 ClassicOverlay로 완전히 대체 (중복 렌더 방지)
- OVERLAY_PAD, LOGO_STRIP_W, LOGO_STRIP_H, PHOTO_W 상수는 PostWorkoutLogModal.tsx의 모듈 레벨 상수 그대로 사용
- WorkoutCameraOverlay의 PHOTO_H는 자체 상수(Math.round(PHOTO_W * (4/3))) 사용
