BUG FIX: Routine selection shows all gym machines instead of only routine machines
==================================================

ROOT CAUSE (confirmed from code review):
In PostWorkoutLogModal.tsx, the ExerciseSelectStep renders machines like this:

  const machines = gym.machines.filter(m => matchesMuscle(m.targetMuscle))

This always shows ALL machines in the gym that match the selected muscle.
The preloadedIds variable (which holds the routine's machine IDs) is only
used for visual highlighting (exCardPreloaded style), NOT for filtering.

So when a user selects "이전 운동일지 참고하기", "헬스장 추천 루틴", or "다른 유저 루틴",
the machine selection screen still shows all gym machines instead of only
the machines from the selected routine.

Step 2: Find the ExerciseSelectStep component or the 'exercise-select' case in the step renderer.
Find this exact line (or similar):
  const machines = gym.machines.filter(m => matchesMuscle(m.targetMuscle))

Step 3: Add a filter that restricts to preloadedIds when they exist.
Change the machines variable to:

  const hasPreloaded = preloadedIds.size > 0
  const machines = gym.machines.filter(m => {
    if (!matchesMuscle(m.targetMuscle)) return false
    if (hasPreloaded) return preloadedIds.has(m.id)
    return true
  })

This means:
  - No routine selected (Start Fresh / 새 루틴 작성하기):
    preloadedIds is empty → show all gym machines matching muscle ✅
  - Routine selected (이전 운동일지 / 헬스장 추천 / 다른 유저):
    preloadedIds has IDs → show ONLY those machines ✅
