[기능추가] 머신 다중 타겟부위 지원 (콤마 방식) + 카드 배지 2줄 표시
================================================================================
※ 한 머신이 2개 부위를 가질 수 있게 지원 (예: target_muscle = "Chest, Shoulder").
※ 저장 형식은 콤마구분 문자열(방식 A). category 필드가 이미 쓰는 검증된 패턴을 따름.
※ 하위호환: 단일값("Chest")도 그대로 동작 (parseMuscles가 ['Chest']로 처리).
※ MachineCard 배지 부분만 구조 변경 허용됨(사용자 승인). 그 외 MachineCard 구조/이미지/
  푸터/뼈대는 절대 건드리지 말 것.

■ 핵심 설계
- parseMuscles(s) = s.split(',').map(x=>x.trim()).filter(Boolean)  ← 콤마 파싱 헬퍼(모듈화)
  · 반드시 trim 포함 ("Chest, Shoulder"처럼 콤마 뒤 공백이 있으므로 필수)
- 필터/검색: 단일 비교(===) → parseMuscles(...).some()/includes()
- 부위 칩 목록: map → flatMap(parseMuscles)
- 카드 배지: 부위 1개면 기존처럼 pill 1개, 2개면 pill 2개 세로 2줄 (grid는 더 작게)

■ 변경/생성 파일
  [생성] (없음 — parseMuscles는 기존 splitUtils.ts에 추가)
  [수정] src/lib/splitUtils.ts               ← parseMuscles 헬퍼 추가

  [수정] src/screens/FindGymScreen.tsx        ← 부위 칩/필터
  [수정] src/components/MachineCard.tsx        ← 배지 2줄 (배지 부분만 구조 변경)

  [수정] src/screens/flow/GymDetailModal.tsx   ← 머신 탭 부위 필터(있으면)

⚠ Windows(CRLF) 가능 — str_replace 실패 시 Read로 확인 후 맞출 것.
⚠ 색상(C/R/T)/네비 불변. MachineCard는 '배지(musclePill) 부분'만 수정, 나머지 금지.

// 머신 targetMuscle 문자열을 부위 배열로 파싱 (콤마구분, 공백 trim)
// 단일값 "Chest" → ["Chest"], 다중값 "Chest, Shoulder" → ["Chest","Shoulder"]
export function parseMuscles(targetMuscle?: string | null): string[] {
  if (!targetMuscle) return [];
  return targetMuscle.split(',').map(m => m.trim()).filter(Boolean);
}
