FIX: Filter - show only brands that match selected muscle
==================================================

ROOT CAUSE (confirmed from code review):
The brand filter list always shows ALL brands regardless of which muscle is selected.
When user selects muscle "Back" then brand "Life Fitness",
if Life Fitness has no Back machines, result is 0 and user thinks filter is broken.

The fix: brand filter options must dynamically update based on activeMuscle.
Only show brands that have at least one machine matching the currently selected muscle.

CURRENT CODE (wrong):
  const brands = useMemo(
    () => ['All', ...[...new Set(allMachines.map(m => m.brand))].sort()],
    [allMachines],
  );

This always builds brands from ALL machines, ignoring activeMuscle.

NEW CODE (correct):
  const brands = useMemo(() => {
    const sourceMachines = activeMuscle === 'All'
      ? allMachines
      : allMachines.filter(m =>
          m.targetMuscle?.toLowerCase() === activeMuscle.toLowerCase()
        )
    const uniqueBrands = [...new Set(sourceMachines.map(m => m.brand))].sort()
    return ['All', ...uniqueBrands]
  }, [allMachines, activeMuscle])

This means:
  - When activeMuscle === 'All': show all brands (same as before)
  - When activeMuscle === 'Back': show only brands that have at least one Back machine
