## 1. LeftColOverlay 수정

### 1-1. 수행 루틴 표시 방식 변경

브랜드와 머신명을 한 줄로, 세트는 각 줄에 표시.

기존:
```tsx
            <View key={ex.id} style={{ marginBottom: 10 }}>
              <Text style={{ fontSize: 9, fontWeight: '700', color: tc, opacity: 0.7, letterSpacing: 0.8 }}>
                {`[${ex.brand.toUpperCase()}]`}
              </Text>
              <Text style={{ fontSize: 11, fontWeight: '900', color: tc, letterSpacing: 0.3, marginBottom: 2 }}>
                {ex.name.toUpperCase()}
              </Text>
              {sets.map((st, si) => (
                <Text key={si} style={{ fontSize: 9, fontWeight: '600', color: tc, opacity: 0.85, lineHeight: 14 }}>
                  {`S${si + 1}  ${st.weight}kg × ${st.reps}`}
                </Text>
              ))}
            </View>
```

변경 후:
```tsx
            <View key={ex.id} style={{ marginBottom: 10 }}>
              <Text style={{ fontSize: 10, fontWeight: '900', color: tc, letterSpacing: 0.3, marginBottom: 3 }} numberOfLines={1}>
                {`[${ex.brand.toUpperCase()}] ${ex.name.toUpperCase()}`}
              </Text>
              {sets.map((st, si) => (
                <Text key={si} style={{ fontSize: 9, fontWeight: '600', color: tc, opacity: 0.85, lineHeight: 14 }}>
                  {`S${si + 1}  ${st.weight}kg × ${st.reps}`}
                </Text>
              ))}
            </View>
```

### 1-2. 하단 우측 로고 크기 15% 축소

기존:

## 3. 화면 UI 개선

### 3-1. '운동 후 사진을 찍어보세요 (선택)' 텍스트 삭제

기존:
```tsx
        <Text style={s.hint}>운동 후 사진을 찍어보세요 (선택)</Text>
```
이 줄을 완전히 삭제한다.

### 3-2. 레이아웃 스타일 버튼 명칭 변경 (classic→1, leftcol→2, grid→3)

기존:
```tsx
                  { key: 'classic', label: 'Classic' },
                  { key: 'leftcol', label: 'Left Col' },
                  { key: 'grid',    label: 'Grid' },
```

변경 후:
```tsx
                  { key: 'classic', label: '1' },
                  { key: 'leftcol', label: '2' },
                  { key: 'grid',    label: '3' },
```

### 3-3. 레이아웃 스타일 버튼 + 텍스트 색상 컬러칩을 한 줄로 배치

기존 레이아웃 스타일 블록과 텍스트 색상 블록이 세로로 따로 배치되어 있다.
이를 하나의 가로 행으로 합친다.

기존:
```tsx
            {/* Overlay style selector */}
            <View style={{ marginBottom: 16 }}>
              <Text style={s.colorPickerLabel}>레이아웃 스타일</Text>
              <View style={{ flexDirection: 'row', gap: 8 }}>
                {([
                  { key: 'classic', label: '1' },
                  { key: 'leftcol', label: '2' },
                  { key: 'grid',    label: '3' },
                ] as { key: OverlayStyle; label: string }[]).map(opt => (
                  <TouchableOpacity
                    key={opt.key}
                    style={[...]}
                    onPress={() => setOverlayStyle(opt.key)}
                    activeOpacity={0.8}
                  >
                    <Text style={[...]}>{opt.label}</Text>
                  </TouchableOpacity>
                ))}
              </View>
            </View>

            {/* Text colour selector */}
            <View style={s.colorPickerWrap}>
              <Text style={s.colorPickerLabel}>텍스트 색상</Text>
              <ScrollView horizontal showsHorizontalScrollIndicator={false} style={s.colorPickerRow}>
                {TEXT_COLORS.map(opt => (
                  ...
                ))}
              </ScrollView>
            </View>
```

변경 후 (두 블록을 하나의 가로 행으로):
```tsx
            {/* 레이아웃 스타일 + 텍스트 색상 한 줄 */}
            <View style={{ flexDirection: 'row', alignItems: 'center', marginBottom: 16, gap: 10 }}>
              {/* 스타일 버튼 3개 */}
              <View style={{ flexDirection: 'row', gap: 6 }}>
                {([
                  { key: 'classic', label: '1' },
                  { key: 'leftcol', label: '2' },
                  { key: 'grid',    label: '3' },
                ] as { key: OverlayStyle; label: string }[]).map(opt => (
                  <TouchableOpacity
                    key={opt.key}
                    style={[
                      {
                        width: 34,
                        height: 34,
                        borderRadius: R.pill,
                        borderWidth: 1.5,
                        borderColor: C.border,
                        backgroundColor: C.surface,
                        alignItems: 'center',
                        justifyContent: 'center',
                      },
                      overlayStyle === opt.key && {
                        backgroundColor: C.accentBg,
                        borderColor: C.accent,
                      },
                    ]}
                    onPress={() => setOverlayStyle(opt.key)}
                    activeOpacity={0.8}
                  >
                    <Text style={[
                      { fontSize: 13, fontWeight: '800', color: C.textSub },
                      overlayStyle === opt.key && { color: C.accent },
                    ]}>
                      {opt.label}
                    </Text>
                  </TouchableOpacity>
                ))}
              </View>

              {/* 구분선 */}
              <View style={{ width: 1, height: 28, backgroundColor: C.border }} />

              {/* 컬러칩 가로 스크롤 */}
              <ScrollView
                horizontal
                showsHorizontalScrollIndicator={false}
                style={{ flex: 1 }}
                contentContainerStyle={{ flexDirection: 'row', gap: 10, alignItems: 'center' }}
              >
                {TEXT_COLORS.map(opt => (
                  <TouchableOpacity
                    key={opt.hex}
                    style={[
                      s.colorChip,
                      { backgroundColor: opt.hex },
                      textColor === opt.hex && s.colorChipActive,
                    ]}
                    onPress={() => { setTextColor(opt.hex); onColorChange(opt.hex); }}
                    activeOpacity={0.8}
                  />
                ))}
              </ScrollView>
            </View>
```

기존의 `s.colorPickerWrap`, `s.colorPickerLabel`, `s.colorPickerRow` 관련 블록은 위로 완전히 대체되었으므로 삭제한다.
